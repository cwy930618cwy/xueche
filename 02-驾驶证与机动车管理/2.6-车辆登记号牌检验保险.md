# 2.6~2.8 故事：一辆捷达的一辈子

> 这一篇讲：**车（不是人）的那些手续** —— 登记、号牌、检验、保险。
> 记住前面那条口诀：**车 = 登记，人 = 核发。**
> 出场：老王、周敏（一窗通）、马三（加塞王）、刘建国（白手套）

---

## 开场 · 老王的捷达

```
   老王的车：2018 年的捷达
   车牌：冀 X·12345
   登记地：清河县车管所  ← 这辆车的"户口"在这儿
```

```
   ╭─────────╮
   │ ⊖  ⊙  ⊖ │
   │    ‿    │     老王，车主
   ╰────┬────╯
     ／ │ ＼
   〔车钥匙〕
```

## 第一幕 · 出生：注册登记（上牌）

2018 年，老王把捷达买回家，第一件事——**上牌**。

```
   买车 → 去登记地车管所【注册登记】 → 拿号牌、行驶证、登记证书
   
   ┌────────────────┐
   │ 号牌：冀X·12345 │
   │ 行驶证          │     ← 车的"身份证"
   │ 登记证书        │     ← 车的"房产证"
   └────────────────┘
```

周敏："这叫**注册登记**，就是给车上户口。车管所受理后 **2 日内**办结。"

> 🔑 **口诀：买车上牌叫注册，车管所两天就办完。**

---

## 第二幕 · 变化：变更登记（改了就要报）

### 场景一：老王把车喷成蓝色

老王嫌白色车太普通，把捷达喷成了蓝色。

```
   改变车身颜色
        ↓
   ┌──────────────────────────┐
   │  变更后【10 日内】         │
   │  向登记地车管所申请变更登记 │
   └──────────────────────────┘
```

周敏："**10 天内来办**，不然就是'擅自改变车身颜色'。"

**同样要办变更登记的还有**：

```
   ┌────────────────────────────────────┐
   │  ① 改变车身颜色                     │
   │  ② 更换发动机                       │
   │  ③ 更换车身或者车架                 │
   │  ④ 因质量问题更换整车               │
   │  ⑤ 营运 ↔ 非营运（使用性质变了）    │
   │  ⑥ 机动车所有人的住所迁出/迁入      │
   │  ⑦ 所有人姓名（单位名称）变更        │
   └────────────────────────────────────┘
```

> 🔑 **口诀：改颜色、换发动机、换车架 —— 十天内变更登记。**

---

## 第三幕 · 卖车：转移登记（过户）

老王开了八年，把捷达卖给了马三。

```
   ╭─────────╮
   │ ██   ██ │
   │    ◡    │     马三（加塞王），买主
   ╰────┬────╯
   〔钱袋子〕
```

周敏提醒老王："**车交付之日起 30 日内，去办转移登记。**"

```
   交车日 ─────30 日内────→ 办理转移登记（过户）
        │
        └─ 从"车交给对方"那天开始算，不是签合同那天
```

老王："**不办行不行？**"

周敏："**后患无穷**——"

```
   ❌ 车还是你的名下
      → 马三闯红灯、超速、撞人，罚单先找你
      → 车出了事故，你可能被牵连
      → 马三再转卖，链条越来越乱
```

> 🔑 **口诀：卖车过户三十天，从交车那天算；不过户，罚单先找原车主。**

### 另外一个：注销登记

捷达开了十五年，该报废了 —— **注销登记**（车的"销户"）。

```
   报废 / 灭失 / 不再使用 → 【注销登记】
```

> 🔑 **口诀：车报废了要销户，别让车牌跟着你一辈子。**

## 第四幕 · 号牌：一车一牌，不能乱来

马三买完车，动了歪脑筋。

### 场景一：马三把泥糊在牌照上

```
   正确：                    马三的做法：
   ┌──────────┐              ┌──────────┐
   │ 冀X·12345 │              │ ▓▓▓▓▓▓▓ │  ← 泥糊住
   └──────────┘              └──────────┘
      清清楚楚                  故意遮挡
```

刘建国（白手套）一挥手把他拦下：

```
   ╔═════════╗
   ║ ⊙     ⊙ ║
   ║    ─    ║     刘建国
   ╚════┬════╝
   〔白手套〕
```

"**故意遮挡、污损号牌 —— 记 9 分。**"

```
   ┌────────────────────────────────────┐
   │  未悬挂号牌 / 故意遮挡、污损号牌     │ → 记 9 分
   │  使用其他车辆的号牌                  │ → 记 12 分
   │  伪造、变造号牌                      │ → 记 12 分
   └────────────────────────────────────┘
```

### 场景二：马三借了块牌

马三新车还没上牌，借了老王的旧牌挂上 —— 被查：

"**使用其他车辆的机动车号牌 —— 记 12 分**，扣车、拘留都有可能。"

> 🔑 **口诀：一车一牌别乱挂；遮挡污损九分，借用别人的十二分。**

### 号牌丢了怎么办？

```
   号牌 / 行驶证 / 登记证书 丢了
            ↓
   向【登记地】车管所申请补领  ← 记住"车登"！
```

（和驾照不一样：驾照丢了全国都能补，车牌丢了得回登记地。）

## 第五幕 · 检验：给车做"体检"

### 非营运小微型客车（9 座及以下，面包车除外）的新规

```
   第 1 年 ─── 第 2 年 ─── 第 4 年 ─── 第 6 年 ─── 第 8 年 ─── 第 10 年 ──→ 10 年以上
      │           │           │          │           │            │            │
    免检      领标志      领标志      【上线】     领标志      【上线】      每年 1 次
                                    检验                      检验     （15 年以上每 6 个月 1 次）
```

```
   ┌──────────────────────────────────────────┐
   │  10 年内：第 6、10 年【上线检验】           │
   │          第 2、4、8 年只需【申领检验标志】  │
   │  10 年以上：每年 1 次                       │
   │  15 年以上：每 6 个月 1 次                  │
   └──────────────────────────────────────────┘
```

### 忘了年检会怎样？

```
   开着逾期未检验的车上路
            ↓
   ┌────────────────────────────────┐
   │  罚款 + 记分                    │
   │  连续 3 个周期没检 → 强制报废    │
   │  出了事故，保险公司可以拒赔      │
   └────────────────────────────────┘
```

> 🔑 **口诀：小车十年内，第六第十上线检；十五年后半年一检，逾期不检要赔钱。**

## 第六幕 · 保险：交强险是"保别人"的

### 交强险是强制的

```
   ┌──═════════════════════════════┐
   ║  交强险 = 机动车交通事故责任     ║
   ║           强制保险              ║
   ║                                ║
   ║  【必须买】不买不能上路          ║
   └═══════════════════════════════┘
```

### 不买会怎样？

马三为了省钱没买交强险，被刘建国查到：

```
   ┌────────────────────────────────────┐
   │  扣留车辆                           │
   │  + 处【应缴保险费 2 倍】的罚款       │
   │  补办交强险后才能领回               │
   └────────────────────────────────────┘
```

> 🔑 **口诀：交强险强制买，不买扣车还罚两倍保费。**

### 交强险赔的是"别人"

老王解释给小雅听：

```
   ┌────────────────────────────────────┐
   │  交强险赔的是【对方】，不赔你自己     │
   │                                    │
   │  撞了别人的车 → 赔对方              │
   │  撞了行人     → 赔行人              │
   │  你自己车坏了 → 【不赔】，要靠商业险 │
   └────────────────────────────────────┘
```

### 商业险是"加餐"

| 险种 | 保什么 |
| --- | --- |
| **交强险** | 强制，赔对方（限额内） |
| **第三者责任险** | 交强险不够赔的部分，赔对方 |
| **车损险** | 赔**自己**的车 |
| **座位险 / 车上人员险** | 赔自己车上的乘客 |

老王："**交强险是底线，三者险才是保命的。** 撞了豪车，交强险那点钱根本不够。"

> 🔑 **口诀：交强险赔别人不赔自己；自己的车要买车损险。**

### 出险后别忘了

```
   发生事故 → 报警 + 报保险 → 保留现场照片 → 等定损
   
   ⚠️ 逃逸、酒驾、无证 → 保险公司可以拒赔
```

## 一句话总结

> **车的一生：注册上牌 → 改了十天内变更 → 卖车三十天内过户 → 报废注销。**
> **号牌一车一副，遮挡九分、借用十二分，丢了回登记地补。**
> **小车第六第十上线检，十五年后半年一检。**
> **交强险强制买，不买扣车罚两倍；它赔别人不赔自己。**
