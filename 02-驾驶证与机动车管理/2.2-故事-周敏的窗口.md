# 2.2 故事：周敏的窗口

> 这一篇只讲一件事：**证拿到手以后，什么时候换、丢了怎么办、谁要审验。**
> 出场：周敏（一窗通）、老王、小雅、王二江、王老爷子

---

## 开场 · 车管所大厅

```
   ┌──────────────────────────────────────────┐
   │              车 管 所 大 厅                │
   │                                          │
   │    1 号窗口   ╭─────────╮                 │
   │   换证/补证   │ ⊙     ⊙ │                 │
   │               │    ‿    │  周敏（一窗通）  │
   │               ╰────┬────╯                 │
   │               〔窗 │ 口〕                 │
   │                                          │
   │   排队中：老王、二江、老爷子、小雅……       │
   └──────────────────────────────────────────┘
```

## 第一幕 · 老王换证：有效期怎么"升级"

老王把证递进去："周姐，我证快到期了。"

周敏看了一眼："你这本 6 年到了。**这 6 年每个记分周期都没记满 12 分，所以这次给你换 10 年的。**"

```
   有效期的"升级"之路
   ┌──────────┐      每个周期都没记满 12 分     ┌──────────┐
   │  6  年   │  ───────────────────────────→  │  10 年   │
   │ （初次） │                                 │          │
   └──────────┘                                 └────┬─────┘
                                                      │
                       每个周期都没记满 12 分          │
                       ┌─────────────────────────────┘
                       ▼
                 ┌──────────┐
                 │ 长期有效 │  ← 老王再熬 10 年就是它
                 └──────────┘
```

老王乐了："那我 10 年后要是也没扣满过，是不是就**终身免换**了？"

周敏："对，**长期有效**，不用再换了。前提：**这 10 年里每个记分周期都没记满 12 分。**"

> 🔑 **口诀：六年一升十年，十年一升长期；前提是每个周期都别记满十二分。**

### 什么时候能来换？

小雅问："那得等最后一天来换吗？"

周敏摇头："**期满前 90 日内**就能换，别掐着点来。"

```
   换证窗口期
   ┌──────────────┬────────────────────┬──────────┐
   │   还不能换    │   ✅ 可以换（90 日） │  过期了！ │
   │              │                    │  不能开车 │
   └──────────────┴────────────────────┴──────────┘
          ↑                 ↑                  ↑
       提前 91 天       提前 90 天内        有效期届满
```

> 🔑 **口诀：换证提前九十天，早去早省心；过期还开车，等于无证驾驶。**

---

## 第二幕 · 小雅把证弄丢了

小雅在包里翻了半天，脸白了："姐……**我证丢了**。"

```
    ╲       ╱
   ╭─────────╮
   │ ◕     ◕ │
   │    ‿    │     小雅：证没了……
   ╰────┬────╯
   〔空书包〕
```

周敏头都没抬："**补证，随时能办。** 带着身份证来，填个表，当场就能拿新的。"

```
   补证流程
   身份证 → 填表 → 当场拿新证
   （不用挂失、不用等、不用回原发证地）
```

"**在哪都能补** —— 你证是在老家发的，在这儿也能补，全国通办。"

老王在旁边补刀："**补完记得把旧的作废** —— 如果旧证被人捡去用，麻烦的是你。"

> 🔑 **口诀：证丢了别慌，身份证一递当场补；全国通办，不用回原地。**

---

## 第三幕 · 二江来审验（大车司机的"年终考"）

二江 A2 的证，也来排队。

```
   ╭═════════╗
   │ ▬     ▬ │
   │    ─    │     王二江（拖斗将军，A2）
   ╰────┬────╯
   〔对讲机〕
```

周敏："**你是 A2，得年审。**"

```
   谁要审验？
   ┌────────────────────────────────────┐
   │  A 类、B 类（大客、牵引、公交、      │
   │  中客、大货）→ 要审验                │
   │                                    │
   │  C 类（小车）→ 平时不用审验，        │
   │               到期换证就行           │
   └────────────────────────────────────┘
```

### 什么时候审？

"**每个记分周期结束后 30 日内**，来车管所。"

```
   记分周期结束 ──30 日内──→ 来审验
   （比如你的周期是每年 5 月 20 日结束，
     那就得在 6 月 19 日前来）
```

### 免审小福利

二江苦着脸："每个周期都跑一趟，累。"

周敏笑了："**你这个周期一分都没被记吧？那就免了，不用跑。**"

```
   ┌────────────────────────────────┐
   │  本记分周期【零记分】→ 免予审验 │
   │  本记分周期【有记分】→ 30 日内来 │
   └────────────────────────────────┘
```

> ⚠️ 但有一种情况**不管有没有记分都得来**：发生交通事故造成人员死亡、承担同等以上责任、但没被吊销驾照的，本周期结束后 30 日内必须接受审验。

> 🔑 **口诀：大车周期后三十天审验；零记分免跑一趟，出了人命必须来。**

---

## 第四幕 · 老爷子 72 岁：每年得交体检表

王老爷子也来了，拿着一张体检表。

```
   ╭─────────╮
   │ ⊖     ⊖ │
   │   ≡≡≡   │     王老爷子，72 岁
   ╰────┬────╯
     ／ │ ┃
```

周敏接过表："老爷子，您这年纪——**每年得交一次身体条件证明**。"

```
   70 周岁以上
   ┌──────────────────────────────────┐
   │  每年一个记分周期结束后 30 日内     │
   │  提交【身体条件证明】              │
   │  还要通过记忆力、判断力、反应力测试 │
   └──────────────────────────────────┘
```

老爷子嘟囔："我吃的盐比你走的路多，还得年年体检……"

老王在旁边笑："爸，这是为了您好，也为了路上其他人好。"

> 🔑 **口诀：七十岁起年年检，交完体检才能继续开。**

---

## 第五幕 · 小雅搬家了：信息变更 30 日

> 这幕有点绕（新家旧家分不清），详细版 👉 [2.2-故事-小雅搬家了.md](./2.2-故事-小雅搬家了.md)
> （清河县 → 江州市，一张表分清"信息变更"和"转入换证"）

小雅突然想起："对了姐，我刚搬了家，**证上的地址还是老地址**！"

周敏："**变更后 30 日内**来换证。"

```
   搬家 / 改名 / 身份证号变了
            ↓
   ┌────────────────────────┐
   │  30 日内申请换证        │
   └────────────────────────┘
```

小雅："那要是**户口迁到外市**了呢？"

周敏："那就办**转入换证**，到**迁入地**的车管所办，以后就在那边管了。"

```
   转入换证
   户籍迁出原地  ──→  到【迁入地】车管所换证
   在别的地方住  ──→  也可以向【居住地】车管所申请换证
```

> 🔑 **口诀：搬家改名三十天内换，迁户口去新家那边办。**

---

## 速查表

| 事项 | 时间 / 条件 | 去哪办 |
| --- | --- | --- |
| **期满换证** | 期满前 **90 日**内 | 核发地或核发地以外车管所（全国通办） |
| **补证** | 遗失后随时申请 | 同上，当场拿新证 |
| **信息变更**（搬家、改名） | 变更后 **30 日**内 | 同上 |
| **转入换证** | 户籍迁出 / 居住地变化 | 迁入地或居住地车管所 |
| **审验**（A/B 类） | 每个记分周期结束后 **30 日**内 | 车管所（零记分可免） |
| **70 周岁以上** | 每年提交**身体条件证明** | 车管所 |
| 有效期升级 | 6 年 → 10 年 → 长期（每个周期都没记满 12 分） | — |

---

## 一句话总结

> **换证提前九十天，六年换十、十年换长期，前提是从没记满过十二分。**
> **证丢了当场补、全国通办；搬家改名三十天内换。**
> **大车周期后三十天审验（零记分免跑），七十岁起年年交体检。**
