# 2.2 故事：四关到底考什么

> 小雅拿到大纲就懵了，孙教练拿着课程表，一关一关给她讲明白。
> 出场：小雅、孙教练、老王、王小龙、豆豆、王大柱

---

## 开场 · 课程表前

```
   ╲       ╱                    ╭─────────╮
  ╭─────────╮                  │ ⊙     ⊙ │
  │ ◕     ◕ │                  │   ○     │
  │    ‿    │                  ╰────┬────╯
  ╰────┬────╯                    ／ │ ＼
   〔大纲〕                      〔课程表〕
```

小雅举着考试大纲："教练，这四关到底都考啥啊？"

孙教练把课程表往墙上一挂："来，我给你讲透。"

---

## 第一关 · 科目一：考的是"脑子里的规矩"

孙教练扔给她一本厚厚的题册："这一关不摸车，**考的全是规矩**。"

```
   科目一 七大块
   ┌────────────────────────────────────┐
   │ ① 法律、法规和规章                  │
   │ ② 交通信号（灯 / 标志 / 标线 / 手势）│
   │ ③ 安全行车、文明驾驶                │
   │ ④ 复杂道路：高速、山区、桥隧、夜间、│
   │    恶劣天气                        │
   │ ⑤ 紧急处置：爆胎、转向失控、制动失灵│
   │ ⑥ 车辆构造、安全装置、日常检查      │
   │ ⑦ 事故后的自救、急救、危险物品常识  │
   └────────────────────────────────────┘
```

小雅翻了两页，抬头："等等……这不就是**我现在背的那本笔记**吗？"

老王端着茶杯点点头："对，**你手上那本笔记，基本就是科目一的全部内容。**"

### 学这些到底有啥用？

小雅嘟囔："背这些条文，开车用得上吗？"

孙教练举了两个例子：

> **场景一（紧急处置）**：高速上左前轮突然爆胎，第一反应是什么？
> **A. 猛踩刹车　B. 急打方向　C. 握稳方向、缓踩刹车、慢慢靠边**
> 答案是 C。猛踩刹车、急打方向 = 翻车。**这种题不会做，真遇上就是拿命赌。**

> **场景二（文明驾驶）**：后面有救护车拉警报，怎么办？
> 减速让行、依次让出通道。**这题考的不是罚款，是人命。**

| 项目 | 内容 |
| --- | --- |
| 题量 | 100 题 |
| 题型 | **判断 + 单选**（没有多选） |
| 分值 | 每题 1 分，满分 100 |
| 合格 | **90 分** |
| 时长 | 45 分钟 |

> 🔑 **口诀：科一考规矩，一百道判断单选，九十分过关，四十五分钟。**

---

## 第二关 · 科目二：考的是"方寸之间的手感"

孙教练把她带到训练场："这一关不下路，全在场地里，**考的是车速控制和点位感**。"

### 小车（C1）五项

```
   ① 倒车入库            ② 坡道定点停车和起步        ③ 侧方停车

      ┌────────┐              ╱╱╱╱╱╱╱╱                ┌───┐
      │ ┌──┐   │             ╱  ■停车点 ╱               │ ▭ │ ←车位
      │ │库│ ◐ │            ╱________╱                 │   │
      │ └──┘   │             坡道                      └───┘
      └────────┘
      倒进去再出来            停准了还得开上去           路边车位塞进去


   ④ 曲线行驶              ⑤ 直角转弯
       ∽∽∽∽∽                  ┌──────
       S 弯，别压线            │
                              │ ← 直角，别压角
```

### 为什么 C2（自动挡）少考一项？

小雅数了数："我考 C1 是五项，那小龙他学 C2 呢？"

孙教练："**C2 只有四项，取消'坡道定点停车和起步'。**"

```
   C1（手动挡）：5 项  ── 多一项"坡道定点停车和起步"
   C2（自动挡）：4 项  ── 没有坡道
```

"为啥？**自动挡不会熄火、不会往后溜车**，坡道起步对它来说没难度，考它没意义。手动挡就不一样了——离合抬快了熄火，抬慢了后溜，所以必须考。"

### 分数线：小车 80，大车 90

小雅看到分数愣了："**科目二只要 80 分？不是 90 吗？**"

孙教练敲黑板："**小车 80 分合格，大车 90 分。** 你大柱哥当年考 B2 大货，16 项、90 分才过，比你现在难多了。"

```
   ┌──────────────────────────────────┐
   │  科目二合格线                     │
   │  小车 C1/C2  → 80 分（5 项/4 项） │
   │  大车 A1/A2/A3/B1/B2 → 90 分     │
   │                    （16 项）      │
   └──────────────────────────────────┘
```

大车那 16 项都是啥？孙教练数给她听：桩考、坡道定点停车和起步、侧方停车、通过单边桥、曲线行驶、直角转弯、通过限宽门、通过连续障碍、起伏路行驶、窄路掉头，再加上模拟高速公路、连续急弯山区路、隧道、雨（雾）天、湿滑路、紧急情况处置。

| 项目 | 内容 |
| --- | --- |
| 小车 C1 项目 | 5 项 |
| 小车 C2 项目 | **4 项**（取消坡道定点停车和起步） |
| 大车项目 | **16 项** |
| 合格 | **小车 80 分，大车 90 分** |

> 🔑 **口诀：科二考手感；C1 五项 C2 四项，自动挡不考坡道；小车八十就及格，大车十六项要九十。**

---

## 第三关 · 科目三：真刀真枪上路

孙教练拍拍教练车："这一关，**是真上路了**。"

### 16 项，一气呵成

```
   上车准备 → 起步 → 直线行驶 → 加减挡位操作 → 变更车道
        ↓
   靠边停车 → 直行通过路口 → 路口左转弯 → 路口右转弯
        ↓
   通过人行横道线 → 通过学校区域 → 通过公共汽车站
        ↓
   会车 → 超车 → 掉头 → 夜间行驶
```

### 为啥要专门考"通过学校区域、通过公交站"？

小雅："就开过去也要考？"

正说着，小学生豆豆背着书包从路边窜出来。

```
     ╭─────╮
     │ ⊙ ⊙ │
     │  ‿  │     豆豆（小豆丁）
     ╰──┬──╯
      ／│＼
   〔书包比人还大〕
```

孙教练一把踩住副刹："**看见没！学校门口、公交站台，全是突然窜出来的人。** 这两个项目考的不是技术，考的是**你有没有减速、有没有左右看**。"

> **场景**：公交站后面是盲区，公交车一走，可能正有人从车头前跑出来。正确做法：**减速 + 鸣喇叭示意 + 随时准备停车**。

| 项目 | 内容 |
| --- | --- |
| 项目数 | 16 项 |
| 考试里程 | 小型车**不少于 3 公里** |
| 分值 | 满分 100 分 |
| 合格 | **90 分** |

> 🔑 **口诀：科三上路真刀枪，十六项跑够三公里，九十分才放行。**

---

## 第四关 · 科目四：考的是"遇事怎么办"

小雅："最后一关又是理论？和科一不一样吗？"

孙教练："**最大区别：它有多选题。**"

### 严格说，它是科目三的第二部分

```
   科目三 = 道路驾驶技能（路考）
          + 安全文明驾驶常识（俗称"科目四"）
```

### 考什么（五大块）

```
   ┌────────────────────────────────────┐
   │ ① 安全行车和文明驾驶常识            │
   │ ② 交通标志、标线、交警手势的含义    │
   │ ③ 恶劣气象和复杂道路条件下的驾驶    │
   │ ④ 紧急情况下的避险                  │
   │ ⑤ 交通事故处理与急救常识            │
   └────────────────────────────────────┘
```

### 为什么科一没多选、科四有？

小雅："凭啥科一只有单选，科四就有多选？"

老王接过话："**因为真实路况里，正确做法往往不止一个。**"

> **场景**：雨天在高速公路上行车，应该怎么做？
> - ✅ 降低车速
> - ✅ 保持比平时更大的车距
> - ✅ 开启雾灯和近光灯
> - ❌ 紧急制动
>
> **三个都对** —— 单选根本考不出这个，所以科四必须用多选。

小雅试着做了一道多选，只选了两个，系统判错。孙教练在旁边笑："**多选漏选，一样算错。** 这一关每年都有人觉得'我都过了路考还怕理论'，结果栽在这儿。"

| 项目 | 内容 |
| --- | --- |
| 题量 | **50 题** |
| 题型 | 判断 + 单选 + **多选** |
| 分值 | 每题 2 分，满分 100 |
| 合格 | **90 分**（最多错 5 题） |
| 时长 | 45 分钟（以当地为准） |

> 🔑 **口诀：科四考避险，五十题每题两分；多选漏选也算错，九十分过关。**

## 收尾 · 四关速查表

| 关卡 | 考什么 | 题量 / 项目 | 题型 | 合格线 |
| --- | --- | --- | --- | --- |
| **科目一** | 法规、信号、安全行车、复杂道路、紧急处置、车辆构造、自救急救 | 100 题 | 判断 + 单选 | **90 分**（45 分钟） |
| **科目二** | 场地：倒库、坡道、侧方、曲线、直角 | 5 项（C2 4 项）/ 大车 16 项 | 实操 | **小车 80 分 / 大车 90 分** |

---

## 一句话总结

> **科一考规矩（100 题判断单选 90 分），科二考手感（小车 5 项 80 分，C2 不考坡道），**
> **科三考上路（16 项 3 公里 90 分），科四考避险（50 题带多选 90 分）。**
> **记住：只有科目二小车是 80 分，其他全是 90 分。**
