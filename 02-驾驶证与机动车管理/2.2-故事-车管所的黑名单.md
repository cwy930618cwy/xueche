# 2.2 故事：车管所墙上的黑名单

> 这一篇只讲一件事：**哪些人这辈子（或好几年）不能考驾照。**
> 出场：周敏（一窗通）、小雅、马三（加塞王）、张大嘴（劝酒张）

---

## 第一幕 · 窗口后面那面墙

小雅陪老王来换证，一抬头看见车管所墙上贴着一张大字报。

```
   ╭─────────╮
   │ ⊙     ⊙ │
   │    ‿    │     周敏（一窗通）
   ╰────┬────╯
   〔窗 │ 口〕
```

```
  ┌════════════════════════════════════════════┐
  ║            黑  名  单                        ║
  ║  ────────────────────────────────────────  ║
  ║                                            ║
  ║   ① 马  三  ── 撞了人跑了                   ║
  ║   ② 张大嘴  ── 喝多了撞出人命                ║
  ║   ③ 张大嘴  ── 醉驾（营运车）                ║
  ║   ④ 张大嘴  ── 醉驾（普通车）                ║
  ║   ⑤ 马  三  ── 找人替考，证被撤了            ║
  ║   ⑥ 有病的  ── 癫痫、眩晕、精神病…           ║
  ║   ⑦ 沾了毒的 ── 三年内吸毒                   ║
  ║                                            ║
  └────────────────────────────────────────────┘
```

小雅数了数："周姐，这七种人，都是一辈子不能考吗？"

周敏摇头："**不一样，有的三年、有的五年、有的十年、有的是一辈子。**"

---

## 第二幕 · 马三：撞了就跑

```
   ╭─────────╮
   │ ██   ██ │
   │    ◡    │     马三（加塞王）
   ╰────┬────╯
   〔方向盘〕
```

周敏："去年马三在路口撞了人，**一脚油门跑了**。后来被抓回来。"

```
   撞人 → 跑了 → 抓住
   
   结果：吊销驾照 + 终生不得重新取得
   
   ┌──────────────────────────┐
   │  🚫 一辈子不能再考        │
   └──────────────────────────┘
```

> **记忆点**：**造成交通事故后逃逸 → 终身禁驾。**（不用管构不构成犯罪，跑了就是一辈子）

> 🔑 **口诀：撞了就跑，这辈子别想再考。**

---

## 第三幕 · 张大嘴：一杯酒，三种下场

```
   ╭─────────╮
   │ ⊙     ⊙ │
   │  ▔▔▔    │     张大嘴（劝酒张）
   ╰────┬────╯
   〔酒瓶〕
```

周敏："你张叔叔这一张嘴，害了自己三个版本。"

### 版本一：喝出人命

```
   喝酒 → 发生重大事故 → 构成犯罪
   
   ┌──────────────────────────┐
   │  🚫 终生不得重新取得      │
   └──────────────────────────┘
```

> **记忆点**：**酒驾/醉驾发生重大交通事故、构成犯罪的 → 终生。**
> 和"肇事逃逸"并列，这是**两个"一辈子"**。

> 🔑 **口诀：喝出人命，一辈子清零。**

### 版本二：醉驾开普通车（没出大事）

```
   醉驾（小轿车）→ 吊销驾照
   
   ┌──────────────────────────┐
   │  ⏳ 5 年内不得重新申请    │
   └──────────────────────────┘
```

> **记忆点**：**醉酒驾驶机动车（普通车）→ 5 年。**

> 🔑 **口诀：醉驾私家车，五年不能摸。**

### 版本三：醉驾开营运车（大货、大巴、出租）

```
   醉驾（营运车）→ 吊销驾照
   
   ┌──────────────────────────┐
   │  ⏳ 10 年内不得重新申请   │
   │  重新拿到后也不许开营运车 │
   └──────────────────────────┘
```

> **记忆点**：**醉酒驾驶营运机动车 → 10 年**（营运车拉客拉货，罚得更狠）。
> 顺带：**饮酒后**驾驶营运机动车被吊销的，也是 **5 年**。

> 🔑 **口诀：营运车里喝醉，十年不能碰；重考到手也不许再开营运。**

---

## 第四幕 · 马三第二回：找人替考

周敏："马三科目二考了四次没过，花钱找人替考，被抓了。"

```
   以欺骗、贿赂等不正当手段取得驾照
   （替考、作弊、行贿都算）
            ↓
       驾照被撤销
            ↓
   ┌──────────────────────────┐
   │  ⏳ 3 年内不得申请        │
   └──────────────────────────┘
```

"还有那个**替他考试的枪手**，也是 **3 年**内不得申请。"

> **记忆点**：**作弊、替考、贿赂拿到的证 → 撤销 + 3 年。**（买卖双方一起罚）

> 🔑 **口诀：找枪手替考，证没三年白熬；枪手自己也三年。**

---

## 第五幕 · 另外两种人（窗口直接劝退）

| 谁 | 为什么 |
| --- | --- |
| **有妨碍安全驾驶疾病的人** | 癫痫、眩晕症、癔病、震颤麻痹、精神病、痴呆，以及影响肢体活动的神经系统疾病等 |
| **沾了毒的人** | 三年内有吸食、注射毒品行为，或者解除强制隔离戒毒措施**未满三年**，以及长期服用依赖性精神药品成瘾尚未戒除的 |

> **记忆点**：**"病"和"毒"这两个没有年限，是'不得申请'——治好了、戒满了三年，再说。**

> 🔑 **口诀：有病先治病，有毒先戒毒；戒满三年，再来排队。**

---

## 第六幕 · 年限阶梯图（小雅自己画的）

```
   终生  ┃  肇事逃逸
         ┃  酒驾/醉驾发生重大事故构成犯罪
         ┃
   10 年 ┃  醉驾营运机动车
         ┃
    5 年 ┃  醉驾普通机动车
         ┃  酒驾营运机动车被吊销
         ┃
    3 年 ┃  驾照被撤销（作弊/替考/贿赂）
         ┃  三年内有替人考试行为
         ┃
   不定  ┃  妨碍安全驾驶的疾病
         ┃  三年内吸毒 / 戒毒未满三年
   ──────┻──────────────────────────────
```

**口诀**：

> **"跑了、喝出人命 —— 一辈子；"**
> **"醉驾营运 —— 十年；醉驾普通 —— 五年；""
> **"撤销、替考 —— 三年；"**
> **"有病、沾毒 —— 先治病、先戒毒。"**

**人话版**：

> **马三跑了 → 一辈子；张大嘴喝出人命 → 一辈子。**
> **张大嘴喝挂营运车 → 十年；喝挂私家车 → 五年。**
> **马三找枪手 → 撤销，三年。**

---

## 速查表

| 情形 | 多久不能申请 |
| --- | --- |
| 造成交通事故后逃逸 | **终生** |
| 饮酒后/醉酒驾车发生重大交通事故构成犯罪 | **终生** |
| 醉酒驾驶营运机动车 | **10 年**（重考后也不得开营运车） |
| 醉酒驾驶普通机动车 | **5 年** |
| 饮酒后驾驶营运机动车被吊销 | **5 年** |
| 驾照被撤销（作弊、贿赂、替考） | **3 年** |
| 三年内有代替他人考试行为 | **3 年** |
| 癫痫、眩晕、精神病等妨碍安全驾驶疾病 | 不得申请 |
| 三年内吸毒 / 解除强制戒毒未满三年 | 不得申请 |

---

## 一句话总结

> **两条"一辈子"：跑了、喝出人命。**
> **十年营运醉驾，五年普通醉驾，三年撤销替考。**
> **有病、沾毒，先把人和毒解决了再说。**

> **口诀**：**"逃逸、酒驾出大事 → 终生；醉驾 → 五年；醉驾营运 → 十年；撤销、替考 → 三年。"**
