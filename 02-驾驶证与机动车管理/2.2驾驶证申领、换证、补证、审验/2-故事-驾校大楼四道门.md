# 2.2 故事：驾校大楼的四道门

> 这一篇只讲一件事：**多大能考什么车。**
> 把年龄想成一栋楼，每层一扇门，**长到那个岁数，门才给你开**。

---

## 第一幕 · 楼前的四道门

小雅 20 岁生日这天，孙教练把她领到一栋楼前。

```
           驾 校 大 楼（四道门）
  ┌──────────────────────────────────────┐
  │                                      │
  │  4F │ 22 岁 │  A1 大巴   A2 半挂     │  🔒 锁着
  │     │       │  王老爷子   王二江     │    "再等两年"
  ├─────┼───────┼───────────────────────┤
  │  3F │ 21 岁 │  B1 中巴               │  🔒 锁着
  │     │       │  王小满                │    "再等一年"
  ├─────┼───────┼───────────────────────┤
  │  2F │ 20 岁 │  A3 公交   B2 大货     │  🔓 今天开了！
  │     │       │  李红梅     王大柱      │    "生日快乐"
  │     │       │  ───────────────────   │
  │     │       │  C6 房车【双锁】        │  🔒 年龄够了，
  │     │       │  陈小陈                │    但还得先有 C1/C2 满一年
  ├─────┼───────┼───────────────────────┤
  │  1F │ 18 岁 │  C1 C2 C5 F            │  🔓 早开了
  │     │       │  C3 C4 D E M           │    "你两年前就够了"
  └──────────────────────────────────────┘
```

孙教练晃了晃钥匙串："**每一层都有一扇门，门上写着年龄。你多大，就只能进到哪一层。**"

---

## 第二幕 · 1F：18 岁那道门（小龙刚够）

小雅的弟弟王小龙今年**刚满 18**，正站在 1 楼门口探头探脑。

```
   ╭─────────╮
   │◖ ⊙   ⊙ ◗│     王小龙，18 岁
   │    ‿    │
   ╰────┬────╯
   〔摩托车〕
```

孙教练："小龙，你今年能考这些——"

| 车门 | 车型 |
| --- | --- |
| C1 | 小型汽车（手动挡） |
| C2 | 小型自动挡汽车 |
| C5 | 残疾人专用小型自动挡 |
| F | 轻便摩托车 |
| C3 / C4 | 低速载货汽车 / 三轮汽车 |
| D / E | 普通三轮 / 二轮摩托车 |
| M | 轮式专用机械车 |

> **记忆点**：**18 岁 = 小车 + 摩托的门槛。**
> 其中 **C1、C2、C5、F 没有年龄上限**（多大都能开，但 **70 周岁以上每年要交身体条件证明**）；
> **C3、C4、D、E、M 到 60 岁为止。**

---

## 第三幕 · 2F：20 岁那道门（小雅今天刚开）

"**叮——**"孙教练把钥匙插进 2 楼的锁："小雅，你今天生日，**这道门刚给你开的**。"

```
   🔓  A3 城市公交（李红梅开的）
   🔓  B2 大型货车（王大柱开的）
```

小雅乐了："我终于能开大车了！"

孙教练："对，**20 岁起能考 A3 和 B2**。但记住，这两道门 **60 岁就关了**。"

> **记忆点**：**20 岁 = 大货 + 城市公交的门槛（20~60 岁）。**

### 附带一问：C6 房车也在这层，为啥还锁着？

小雅指着 2 楼角落那间小屋："教练，C6 不是也在 20 岁这层吗？怎么还锁着？"

```
    ______          ┌──────────────┐
   / ____ \         │  ┌────────┐  │
  |_|____|_|--------│  │  小屋  │  │
    (o)  (o)        │  └────────┘  │
                    └──────────────┘
                          (o)
```

孙教练："**C6 是双锁，年龄只是第一把。**"

```
   C6 的两把锁
   ┌────────────────────────────────────┐
   │  锁① 年龄：20 ~ 60 周岁   ← 你现在够了 │
   │  锁② 资历：已取得 C1 或 C2           │
   │        满一年，且本周期和最近         │
   │        一个周期没记满 12 分  ← 你还差 │
   └────────────────────────────────────┘
```

邻居陈小陈正好路过，晃了晃手里的驾照："妹子，我 **C1 拿了八年**，去年才增驾的 C6 —— **这玩意儿不管你多大，都得先有小车证熬满一年。**"

小雅算了算："那我得先考 C1，拿到证再等一年……也就是 **21 岁**才能拖房车？"

陈小陈点头："**对，而且这期间别记满 12 分，不然重来。**"

> **记忆点**：**C6 = 年龄 20~60 岁 + 已持 C1/C2 满一年 + 无记满 12 分记录（三个条件同时满足）。**
> 它是唯一一个"年龄够还不够"的车型 —— **凡是拖挂，都要先有小车底子。**
> 60 岁一到，C6 也停（和大车一样）。

---

## 第四幕 · 3F：21 岁那道门（还差一年）

小雅往上跑了两级台阶，被 3 楼的门挡住。

```
   🔒  B1 中型客车（王小满那辆 11 座中巴）
       门上贴着：还差 1 年
```

"哥——"小雅冲楼上喊。小满从窗户探出头："妹子，**我这 B1 得 21 岁才能考**，你再熬一年。"

> **记忆点**：**21 岁 = 中型客车 B1 的门槛（21~60 岁）。**

---

## 第五幕 · 4F：22 岁那道门（还差两年）

再往上一层，锁得更死。

```
   🔒  A1 大型客车（王老爷子坐的大巴）
   🔒  A2 重型牵引挂车（王二江的半挂）
       门上贴着：还差 2 年
```

二江在楼下车里按喇叭："小雅，**A1、A2 是最高那道坎，22 岁**！我当年等得脖子都长了。"

> **记忆点**：**22 岁 = 大型客车 A1、牵引挂车 A2 的门槛（22~60 岁）。**

---

## 第六幕 · 楼顶的两道闸

孙教练指着楼顶："别光顾着往上爬，**上面还有两道闸**——"

```
   ┌────────────────────────────────────────┐
   │  60 岁闸：大车门全部关闭               │
   │           C3 C4 D E M / A3 B2 B1 A1 A2 │
   │           → 到 60 岁这些都不能再考/开了 │
   │           只剩 C1 C2 C5 F 还能开        │
   ├────────────────────────────────────────┤
   │  70 岁闸：每年提交身体条件证明          │
   │           王老爷子 72 岁，每年都得去    │
   └────────────────────────────────────────┘
```

> **记忆点**：**60 岁 —— 大中型车全停；70 岁 —— 小车也要每年体检。**

## 第七幕 · 一句话串起来

晚上小雅在笔记本上写：

```
   18 岁 ──→ 小车 + 摩托        （小龙刚够）
   20 岁 ──→ + 公交 A3、大货 B2 （我今天刚够）
   20 岁 ──→ + 房车 C6？        （年龄够，但还得先有 C1/C2 满一年）
   21 岁 ──→ + 中巴 B1          （还差 1 年）
   22 岁 ──→ + 大客 A1、半挂 A2 （还差 2 年）
   60 岁 ──→ 大车门全关（C6 也关）
   70 岁 ──→ 小车每年体检
```

**口诀（数字版）**：

> **"十八小车，二十货（公交大货），二十一客（中客），二十二大（大客牵引）。"**
> **"房车 C6 看二十，还得先有小车证熬满年。"**
> **"六十关门，七十体检。"**

**口诀（人物版，更好记）**：

> **"小龙 18 骑摩托，小雅 20 开大货，**
> **再熬一年开中巴（21），再熬两年开大巴（22）。"**
> **"小陈的房车拖不得 —— 小车证没满一年，年龄到了也白搭。"**

## 习题（点开看答案）

<details>
<summary>第 1 题</summary>

**申请大型客车（A1）准驾车型的最低年龄是多少？**

**22 周岁**（接受全日制驾驶职业教育的学生 19 周岁）。
</details>

<details>
<summary>第 2 题</summary>

**申请中型客车（B1）的最低年龄是多少？**

**21 周岁**。
</details>

<details>
<summary>第 3 题</summary>

**申请城市公交车（A3）、大型货车（B2）的最低年龄是多少？**

**20 周岁**。
</details>

<details>
<summary>第 4 题</summary>

**小雅今年 20 岁，她现在能考哪些？（多选思路）**

C1、C2、C3、C4、C5、D、E、F、M 都能；**大车里能考 A3、B2**；**还不能考 B1（21）、A1/A2（22）**。
</details>

<details>
<summary>第 5 题</summary>

**年龄到 60 周岁后，大中型车（A1/A2/A3/B1/B2）还能考吗？**

不能。**大中型车准驾车型年龄上限是 60 周岁**；C1、C2、C5、F 没有上限。
</details>

<details>
<summary>第 6 题</summary>

**70 周岁以上的驾驶人，需要做什么？**

**每年提交一次身体条件证明**（并通过记忆力、判断力、反应力等能力测试）。
</details>

<details>
<summary>第 7 题</summary>

**申请轻型牵引挂车（C6）的年龄条件？还要求什么？**

年龄 **20~60 周岁**；另外必须**已取得 C1 或 C2 准驾车型资格一年以上**，且本记分周期和申请前最近一个记分周期**没有记满 12 分**记录。
</details>

<details>
<summary>第 8 题</summary>

**小雅今年 20 岁，能直接考 C6 拖房车吗？**

不能。她年龄够了（20 岁），但**还没有 C1/C2 证**。得先考下 C1 或 C2，**满一年后**（且期间没记满 12 分）才能增驾 C6 —— 算下来最快也得 21 岁。
</details>
