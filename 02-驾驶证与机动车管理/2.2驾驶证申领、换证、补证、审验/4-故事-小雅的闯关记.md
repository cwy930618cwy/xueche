# 2.2 故事：小雅的闯关记

> 这一篇只讲一件事：**考驾照这个过程怎么玩，哪些数字会要命。**
> 把考证想成一个**闯关游戏**：有通关文牒、有血条、有次数上限、有清零机制。
> 出场：小雅、孙教练、王小龙（同期学车的弟弟）、老王

---

## 第一幕 · 通关文牒：只有三年寿命

小雅科目一过了，孙教练递给她一张纸。

```
   ┌─────────────────────────────────┐
   │        学 习 驾 驶 证 明          │
   │                                 │
   │   持有人：王小雅                 │
   │   有效期：3 年                   │
   │                                 │
   │   ┌───────────────────────┐     │
   │   │ ⏳ 3 年后到期，全部清零 │     │
   │   └───────────────────────┘     │
   └─────────────────────────────────┘
```

孙教练："**这张纸是你后面所有关卡的门票，只有 3 年。** 三年内没考完，前面考过的科目**全部作废**，从头再来。"

```
   倒计时
   第 1 年 ─────────────┐
   第 2 年 ─────────────┤  考不完 → 清零重来
   第 3 年 ─────────────┘
```

> 🔑 **口诀：通关文牒三年期，过期统统清为零。**

## 第二幕 · 四道关卡

```
   关卡地图
   ┌──────────────────────────────────────────────┐
   │                                              │
   │  第 1 关  科目一（理论）                       │
   │          100 题 · 判断 + 单选 · 90 分过关      │
   │                    ↓                         │
   │  第 2 关  科目二（场地）                       │
   │          倒车入库 / 坡道 / 侧方 / 曲线 / 直角  │
   │                    ↓                         │
   │  第 3 关  科目三（路考）                       │
   │          上车准备、起步、变道、靠边停车……      │
   │                    ↓                         │
   │  第 4 关  科目四（安全文明驾驶常识）            │
   │          50 题 · 判断 + 单选 + 【多选】· 90 分 │
   │                    ↓                         │
   │                🎉 拿 证                       │
   └──────────────────────────────────────────────┘
```

### 关卡细说：每一关到底考什么

#### 第 1 关 · 科目一（理论）

**考什么**（七大类）：

```
   ① 道路交通安全法律、法规和规章
   ② 交通信号及其含义（灯、标志、标线、交警手势）
   ③ 安全行车、文明驾驶知识
   ④ 高速、山区、桥梁、隧道、夜间、恶劣天气、复杂道路下的安全驾驶
   ⑤ 爆胎、转向失控、制动失灵等紧急情况的临危处置
   ⑥ 机动车总体构造、主要安全装置、日常检查维护常识
   ⑦ 事故后的自救、急救常识，常见危险物品知识
```

| 项目 | 内容 |
| --- | --- |
| 题量 | 100 题 |
| 题型 | **判断 + 单选**（没有多选） |
| 分值 | 每题 1 分，满分 100 |
| 合格 | **90 分** |
| 时长 | 45 分钟 |

---

#### 第 2 关 · 科目二（场地）

**小车（C1）考 5 项**：

```
   ┌────────────────────────────────────┐
   │  1. 倒车入库      ┌──┐ 倒进去再出来 │
   │  2. 坡道定点停车和起步              │ ← C2（自动挡）不考这项
   │  3. 侧方停车      ┌──┐ 路边车位     │
   │  4. 曲线行驶      ∽∽∽ S 弯          │
   │  5. 直角转弯      ┌─── 直角         │
   └────────────────────────────────────┘
```

| 项目 | 内容 |
| --- | --- |
| 小车项目 | 5 项（**C2 自动挡 4 项，取消坡道定点停车和起步**） |
| 大车项目 | **16 项**（桩考、单边桥、连续障碍、窄路掉头、模拟高速/隧道/湿滑路/紧急情况处置等） |
| 分值 | 满分 100 分 |
| 合格 | **小车 80 分**，**大车（A1/A2/A3/B1/B2）90 分** |

> ⚠️ 常考易错：**科目二小车 80 分就及格**，不是 90 分！只有大车才要 90。

---

#### 第 3 关 · 科目三（道路驾驶技能）

**16 项考试内容**：

```
   上车准备 → 起步 → 直线行驶 → 加减挡位操作 → 变更车道
   → 靠边停车 → 直行通过路口 → 路口左转弯 → 路口右转弯
   → 通过人行横道线 → 通过学校区域 → 通过公共汽车站
   → 会车 → 超车 → 掉头 → 夜间行驶
```

| 项目 | 内容 |
| --- | --- |
| 项目数 | 16 项（上面这些） |
| 考试里程 | 小型车**不少于 3 公里** |
| 分值 | 满分 100 分 |
| 合格 | **90 分** |

---

#### 第 4 关 · 科目四（安全文明驾驶常识）

> 严格说它属于"科目三"的第二部分，俗称科目四。

**考什么**：

```
   ① 安全行车和文明驾驶常识
   ② 交通标志、标线、交警手势的含义
   ③ 恶劣气象和复杂道路条件下的安全驾驶
   ④ 紧急情况下的避险
   ⑤ 交通事故处理与急救常识
```

| 项目 | 内容 |
| --- | --- |
| 题量 | **50 题** |
| 题型 | 判断 + 单选 + **多选**（和科一最大的区别） |
| 分值 | 每题 2 分，满分 100 |
| 合格 | **90 分** |
| 时长 | 45 分钟（以当地为准） |

---

> 🔑 **口诀：科一理论、科二场地、科三上路、科四文明。**
> 🔑 **分数口诀：科一科三科四都九十分，科二小车八十分（大车才九十）。**

**冷却时间**（不是想考就能考）：

| 关卡 | 什么时候能约 |
| --- | --- |
| 科目二（小车） | 取得学习驾驶证明**满 10 日**后 |
| 科目三（小车） | 取得学习驾驶证明**满 30 日**后 |

> 部分城市对 C2 等有优化，以当地政策为准。

---

## 第三幕 · 血条：一关两条命

小雅科目二第一次考，倒车入库压线，挂了。

```
   科目二 血条
   ❤ ❤        ← 一次预约 = 正考 1 次 + 补考 1 次
   1  2
   ✗  ○       ← 第一次压线，还剩一条命
```

孙教练："别慌，**每个科目考试一次，不合格可以补考一次**。你还有第二次机会，就在当天。"

小雅第二次稳住，过了。

```
   ❤ ❤
   ✗  ✓       ← 补考过了！
```

> **注意**：不参加补考、或者补考还没过 → **本次考试终止**，得重新预约（**十日后**）。

> 🔑 **口诀：一关两条命，当场挂了还能再战一回；补考也没过，隔十天再来。**

---

## 第四幕 · 最狠的一条：只有 5 次预约机会

弟弟王小龙在旁边快哭了。

```
   ╭─────────╮
   │◖ ⊙   ⊙ ◗│
   │    ‿    │     王小龙，18 岁，科二已经挂了 3 次
   ╰────┬────╯
   〔练车卡〕
```

孙教练："跟你交个底，**科目二和科目三道路驾驶技能考试，预约次数不得超过 5 次**。"

```
   科目二 预约机会
   ┌───┐ ┌───┐ ┌───┐ ┌───┐ ┌───┐
   │ 1 │ │ 2 │ │ 3 │ │ 4 │ │ 5 │
   │ ✗ │ │ ✗ │ │ ✗ │ │ ○ │ │ ○ │     ← 小龙已经用了 3 次
   └───┘ └───┘ └───┘ └───┘ └───┘
                                  ↑
                        第 5 次还不过 →
                        前面考过的科目成绩【全部作废】
```

**注意**：这里的"5 次"是**预约次数**，每次预约里还含"正考 + 补考"，所以实际上是 **最多 10 次上车机会**。

```
   5 次预约 × (正考 1 次 + 补考 1 次) = 最多 10 次上车
```

### 小龙的噩梦

孙教练讲了个真事："去年有个学员，科目二第 5 次没过。他科目一早考过了、科三也练得差不多了——**全作废**，重新报名，从科目一开始。"

```
   第 5 次挂科  ──→  已合格的其他科目成绩作废
                 ──→  重新报名，从科一再来
```

> 🔑 **口诀：科二科三各五次，第五次挂全白费；一次预约两条命，算下来十回机会。**

---

## 第五幕 · 最后一关：科目四和科目一不一样

小雅闯到最后一关，翻了翻题，愣了："**怎么还有多选？**"

孙教练："对，**科目一只有判断和单选，科目四多了多选题** —— 这是很多人轻敌翻车的地方。"

| | 科目一 | 科目四（安全文明驾驶常识） |
| --- | --- | --- |
| 题量 | 100 题 | **50 题** |
| 题型 | 判断 + 单选 | 判断 + 单选 + **多选** |
| 合格 | 90 分 | 90 分 |

> 🔑 **口诀：科一百题无多选，科四五十题有多选——别照着科一的感觉考科四。**

四关全过，小雅把驾照举过头顶。老王在门口等着，端着茶杯："别高兴太早，**后面还有 12 个月实习期**呢。"

## 速查表

| 项目 | 规定 |
| --- | --- |
| 学习驾驶证明有效期 | **3 年**（过期已合格科目作废） |
| 每个科目考试 | 考 1 次，不合格可**补考 1 次** |
| 补考也没过 | 本次终止，**十日后**重新预约 |
| 科目二、科目三预约次数 | 各不超过 **5 次**（合计最多 10 次上车机会） |
| 第 5 次仍不合格 | **已合格的其他科目成绩作废** |
| 小型车预约科目二 | 取得学习驾驶证明**满 10 日** |
| 小型车预约科目三 | 取得学习驾驶证明**满 30 日** |
| 科目一 | 100 题，判断 + 单选，90 分合格 |
| 科目四 | 50 题，判断 + 单选 + **多选**，90 分合格 |

---

## 一句话总结

> **文牒三年、一关两命；科二科三各五次约，第五次挂全清零；**
> **挂了隔十天再来，科四比科一多了多选。**
