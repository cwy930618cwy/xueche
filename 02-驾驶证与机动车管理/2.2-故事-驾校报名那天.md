## 第二幕 · 第一把锁：A1 大巴（王老爷子那辆）

孙教练吹响哨子："**滴滴——站住！A1 大巴，初次申领不能考！**"

```
   ╭─────────╮
   │ ⊖  ⊙  ⊖ │
   │    ‿    │     王老爷子坐的那辆，车长 6 米以上
   ╰────┬────╯     一车几十号人
     ／ │ ＼
```

"你想想，你连小车都没摸过，直接让你拉一车人上高速？**车上几十条人命，不可能。**"

> **道理**：A1 = 大型客车，责任最大，必须**先有别的证，再增驾**。

      | |  | |______│     集装箱挂厢     │
      |_|__|_|      │                    │

"**A2 牵引挂车，也不能。** 你二江叔叔开了十几年大货才增驾的 A2。这玩意儿倒车的时候，车头和挂厢是反着走的，老司机都得练半年。"

> **道理**：A2 = 拖挂，技术难度天花板，得先有 **B1/B2 满 2 年**（或 A1 满 1 年）。

小雅愣住了："凭啥呀？都是大车，凭啥它俩就能？"

## 第七幕 · B2 为什么能直考 —— 大柱的故事

```
   ╭───────────╮
   │ ▮ ⊙   ⊙ ▮ │
   │    ▬▬     │    王大柱，40 岁，B2 大货司机
   ╰─────┬─────╯
     ／／│＼＼
```

孙教练："你大柱哥 20 岁那年，家里等着用钱，哪有闲工夫先考个 C1 再熬三年？他**直接报了大货班**——教练车就是大卡车，从离合开始教，练几个月拿证，直接上路跑运输。"

```
   大柱的考证路（从零开始）
   20 岁 ──→ 直接报 B2 大货班 ──→ 拿证 ──→ 开大卡车
              ↑
        不需要先有别的证
```

### 小雅的疑问："大货不是更危险吗？"

小雅皱起眉头："教练，不对啊。**大货车不是最容易出大事吗？** 新闻里那些大事故，好多都是大货。凭啥它反而能直考？"

孙教练愣了一下，乐了："**你这问题问得比答案值钱。** 来，我给你掰扯清楚。"

**第一层：危险 ≠ 不能直考**

```
   危险程度                    能否初次申领
   ┌────────────────────┐     ┌──────────────┐
   │ B2 大货  ★★★★☆     │────→│   ✅ 能直考   │
   │ B1 中巴  ★★★☆☆     │────→│   🔒 要增驾   │
   │ A1 大巴  ★★★★★     │────→│   🔒 要增驾   │
   │ A3 公交  ★★★☆☆     │────→│   ✅ 能直考   │
   └────────────────────┘     └──────────────┘
        ↑ 这两列根本对不上 → 说明危险程度不是标准
```

**第二层：真正的标准是这两条**

```
   能不能初次申领，只看两件事：

   ① 有没有"从零开始"的完整培训体系
      大货班 ✅（驾校有大货教练车和场地）
      公交定向班 ✅（公交公司送人来培训）

   ② 载不载客
      载客 → 要求你先有驾驶经历（先拿小车证，熬够年头）
      不载客（拉货）→ 可以从零培养
```

**第三层：B2 能直考，但考试要狠得多**

孙教练敲黑板："**国家不是不管，是用更狠的考试来补。** 你考 C1 科目二才 5 项，大柱当年考 B2 **16 项**！"

```
   C1 科目二（5 项）            B2 科目二（16 项）
   ┌────────────────┐        ┌────────────────────────┐
   │ 倒车入库        │        │ 桩考                    │
   │ 坡道定点停车起步 │        │ 坡道定点停车和起步      │
   │ 侧方停车        │        │ 侧方停车 / 曲线行驶      │
   │ 曲线行驶        │        │ 直角转弯 / 通过单边桥    │
   │ 直角转弯        │        │ 通过限宽门 / 连续障碍    │
   └────────────────┘        │ 起伏路 / 窄路掉头        │
                             │ 模拟高速公路             │
                             │ 模拟连续急弯山区路        │
                             │ 模拟隧道 / 雨(雾)天       │
                             │ 模拟湿滑路               │
                             │ 模拟紧急情况处置          │
                             └────────────────────────┘
```

"**用三倍的考试项目，换一个'从零学起'的资格。**"

**第四层：后面还有锁**

"而且 B2 拿证也不是就放任了——"
- **不能拉人**：B2 开不了 B1 中巴（"拉货的不能拉人"）
- **想升级要熬年头**：B2 想增驾 A2 牵引车，得**满 2 年**

### 老王补刀

老王端着茶杯来接闺女，正好听见："大货出事，**多半不是'不会开'，是'超载、疲劳、抢时间'**。那几样归记分和处罚管，不归'能不能直考'管——后面第七章专门讲。"

> **记忆点**：**B2 能直考的真正原因 = 有从零培训体系 + 不载客；代价是科目二 16 项、不能拉人、想升级还得熬。**
> **别记成"大货不危险"——它很危险，只是危险的管法不一样（严考试 + 严记分 + 治超 + 限行）。**

> **真题场景**：判断题"初次申领驾驶证，可以申请大型货车（B2）准驾车型" → **对**。
> 判断题"因为大型货车危险性高，所以初次申领不能申请 B2" → **错**（危险不是判据）。

## 第八幕 · A3 为什么能直考 —— 红梅的故事

小雅还是不服："可 A3 是公交车啊，也拉一车人，凭啥能直考？"

"问得好。"孙教练竖起三根手指，"**三个原因**——"

```
   ╭─────────╮
  )│ ⊙     ⊙ │(     李红梅，42 岁，A3 公交司机
   │    ‿    │
   ╰────┬────╯
   〔公交制服〕
```

**① 定向培养** —— 你婶儿当年是**公交公司招的定向生**，公司掏钱把她送驾校，从零教。招进来的本来就是没证的小年轻，所以要允许直考。

**② 范围特别窄** —— A3 **只能开城市公交车**，不能开长途大巴（那是 A1），也不能开中巴（那是 B1）。

**③ 环境可控** —— 市内跑、有固定线路、有站点、速度低、有调度盯着。

```
   A1 长途大巴                 A3 城市公交
   ┌──────────────┐           ┌──────────────┐
   │ 跨省 / 高速   │           │ 市内 / 低速   │
   │ 几十条人命    │           │ 固定线路      │
   │ 路线不固定    │           │ 有站点停靠    │
   │ 没调度盯着    │           │ 公司调度盯着  │
   ├──────────────┤           ├──────────────┤
   │  ❌ 不能直考  │           │  ✅ 可以直考  │
   └──────────────┘           └──────────────┘
```

> **记忆点**：同样是拉人的大车，**跑长途的（A1）上锁，跑市内固定的（A3）开锁**。

## 第八幕小结 · 四把锁的底层逻辑

孙教练在黑板上写：

```
   ┌───────────────────────────────────────┐
   │                                       │
   │   拉很多人的      → A1 大巴    🔒      │
   │   拉十几个的      → B1 中巴    🔒      │
   │   后面拖东西的    → A2 半挂    🔒      │
   │   （拖挂类）     → C6 房车    🔒      │
   │                                       │
   │   拉货的          → B2 大货    ✅      │
   │   市内公交定向    → A3 公交    ✅      │
   │                                       │
   └───────────────────────────────────────┘
```

**一句话规律**：

> **"拉人的上锁，拉货的开锁；拖挂的统统上锁；公交是特例，公司包教包会。"**
>
> ⚠️ 注意：**"拉货的开锁"不是说大货不危险** —— 大货很危险。能直考是因为"不载客 + 有从零培训体系"，代价是科目二 16 项和后续一堆锁。

小雅听完想了想："那我还是先考 C1 吧，我爸那辆手动挡我还想开呢。"

孙教练点头："**对，C1 最实用，往下还能开自动挡。**"

## 习题（点开看答案）

<details>
<summary>第 1 题</summary>

**初次申领驾驶证，可以直接申请哪种准驾车型？**
A. A1 　B. A2 　C. B1 　D. B2

**D**。B2 大货车可以直接考（A3 也行），A1/A2/B1 都要增驾。
</details>

<details>
<summary>第 2 题</summary>

**判断题：所有大型车辆都不能初次申领。**

**错**。B2（大型货车）和 A3（城市公交车）可以初次申领。
</details>

<details>
<summary>第 3 题</summary>

**初次申领不能直接考的四个车型是哪四个？**

**A1、A2、B1、C6**（大客、牵引挂车、中型客车、轻型牵引挂车）。
</details>

<details>
<summary>第 4 题</summary>

**小雅想开拖挂房车，最少需要什么条件？**

先取得 **C1 或 C2 一年以上**，且本周期和最近一个记分周期没记满 12 分，年龄 20~60 周岁，才能增驾 **C6**。
</details>

<details>
<summary>第 5 题</summary>

**小满的 B1 中巴证是怎么来的？**

先拿 C1（或 C2、B2、A3 等）**三年以上**，再增驾 B1。
</details>

<details>
<summary>第 6 题</summary>

**B2 大货车事故那么多，为什么还允许初次申领？**

**危险程度不是判据。** 能直考的真正原因是：① 驾校有完整的大货培训体系；② **不载客**（B2 开不了 B1 中巴）。
代价是：科目二要考 **16 项**（小车才 5 项）、不能拉人、想增驾 A2 还得满 2 年。
大货的危险靠**记分、治超、限行、疲劳驾驶处罚**来管，不靠"禁止初次申领"。
</details>

<details>
<summary>第 7 题</summary>

**A3 公交和 A1 大巴都是载人的大车，为什么 A3 能直考、A1 不行？**

三个原因：**① 公交公司定向培养**（招进来的人本来没证）；**② 范围窄**（A3 只能开城市公交车）；**③ 环境可控**（市内低速、固定线路、有站点和调度）。
</details>
