# 跟「灯 / 线 / 标志」有关 —— 每个都说故事

> 这是路上最常遇到的八种情况。**记住规律**：越是在号牌上动歪心思，罚得越狠。
> 从红灯冲线到造假套牌，一个比一个重。

---

## ① 闯红灯 / 不按信号灯走 —— 6 分 + 200 元

```
        🚦 红灯
         │
    ┌────┴────┐
    │   →→→   │  马三心想："就一辆车，冲过去！"
    │  🚗💨   │
    └────┬────┘
         ↓
   ╔═════╩═════╗
   ║  砰！侧面撞  ║  横向绿灯的车直接撞上
   ║  6分+200元  ║
   ╚═══════════╝
```

马三赶时间，红灯亮了他一脚油门冲过去。结果十字路口的横向正好是绿灯，"砰"一声被撞了个正着。

> **后果**：闯红灯 = **扣 6 分 + 罚 200 元**。要是撞了人就是大事。
>
> **口诀**：红灯还想冲，六分两百空；宁等三十秒，不抢一秒中。

---

## ② 压单行线、闯禁行区 —— 1 分 + 200~500 元

```
   ════════════╗  ← 单行线（只能往右）
               ║
      🚗 ↖     ║  大柱想抄近道，逆行压线
      （逆行）  ║
   ────────────╝
         ↓
   ╔═══════════╗
   ║ 摄像头拍下  ║  1分 + 200~500元
   ╚═══════════╝
```

大柱赶时间，看到一条单行线，心想"对面没车，拐进去抄近道"。结果路口有摄像头，逆行压线被拍了个正着。

> **后果**：压单行线、闯禁行 = **扣 1 分 + 罚 200~500 元**。
>
> **口诀**：单行线别逆行，压线闯禁都扣分；抄近道省一分，罚了五百才后悔。

---

## ③ 不按规定车道开（直行道转弯）—— 1 分 + 200~500 元

```
   直行车道 ⬆️
      │
      │  🚗↰  马三在直行道直接左转
      │
   ═══╧═══  ← 旁边就是左转道（他偏不走）
         ↓
   ╔═══════════╗
   ║ 占错道了    ║  1分 + 200~500元
   ╚═══════════╝
```

马三排在前面的直行车道，绿灯一亮他没打灯直接从直行道拐进了左转的路。旁边左转道的车都傻眼了——他就该走左转道啊。

> **后果**：不按导向车道行驶 = **扣 1 分 + 罚 200~500 元**。
>
> **口诀**：直行道别转弯，各走各的道线；提前看牌进对道，占错一道也罚钱。

---

## ④ 违反禁令标志（禁行牌）—— 1 分 + 20~200 元

```
   ┌─────────┐
   │ 🚫 禁止驶入│  ← 明明白白写着不让进
   └────┬────┘
        │
       🚗  大柱："这路看着挺宽，应该能走吧？"
        │
        ↓
   ╔═══════════╗
   ║ 牌不让进你进了║  1分 + 20~200元
   ╚═══════════╝
```

大柱开到一条窄路，明明立着"禁止驶入"的牌子，他心想"这路这么宽肯定能过"，硬着头皮开了进去。结果刚进去就被拦下。

> **后果**：违反禁令标志 = **扣 1 分 + 罚 20~200 元**。
>
> **口诀**：禁令标志红圈圈，看见不进是安全；心存侥幸硬要闯，一百分儿也扣完。

## ⑤ 不按规定安装号牌（歪了脏了）—— 3 分 + 200 元

```
      🚗 大柱的车
   ┌─────────────┐
   │  后窗：📋歪着塞 │  ← 牌照斜着、遮住一角
   │   （看不清）   │
   └─────────────┘
         ↓
   ╔═══════════╗
   ║ 牌子没装好   ║  3分 + 200元
   ╚═══════════╝
```

大柱新车上牌，觉得把牌照端端正正拧四个螺丝太麻烦，随手歪着塞在后窗底下，还挡了一角。交警一看：这牌照不完整，算你没按规定安装。

> **后果**：不按规定安装号牌 = **扣 3 分 + 罚 200 元**。
>
> **口诀**：号牌端正好辨认，歪着塞着都算错；四颗螺丝拧到位，别省这点惹扣分。

## ⑥ 故意遮挡、污损号牌 —— 9 分 + 200 元

```
      🚗 马三的车
   ┌─────────────┐
   │ 后窗：📋涂了泥 │  ← 故意糊住、让摄像头拍不清
   │  （泥巴盖满） │
   └─────────────┘
         ↓
   ╔═══════════╗
   ║ 故意让看不清  ║  9分！接近满分了
   ╚═══════════╝
```

马三想干点见不得光的事，怕被摄像头拍到车牌，就拿泥巴把后牌照糊了个严严实实。结果刚开出小区就被交警拦下——你这牌照完全看不清，故意遮挡！

> **后果**：故意遮挡、污损号牌 = **一次扣 9 分**（离 12 分就差 3 分！）+ 罚 200 元。
>
> **口诀**：号牌遮泥涂了脏，一次九分快到顶；摄像头前耍小聪明，到头来自己挖坑埋。

---

## ⑦ 未悬挂号牌上路（新车没牌）—— 9 分 + 200 元 + 扣车

```
      🚗 王小雅的新车
   ┌─────────────┐
   │  前后窗：空空  │  ← 啥牌都没有，裸奔上路
   │   （无号牌）  │
   └─────────────┘
         ↓
   ╔═══════════════╗
   ║ 裸奔上路        ║  9分 + 200元 + 扣车！
   ║ 车都被暂扣了    ║
   ╚═══════════════╝
```

王小雅提了新车，兴奋得当天就想开出去兜风。可正式牌照还没办好，她心想"就开一小段去加油，能有啥事"。结果路上被交警拦下：没挂牌照，车先扣下，人扣 9 分。

> **后果**：未悬挂号牌上路 = **扣 9 分 + 罚 200 元 + 扣留车辆**。
>
> **口诀**：新车没牌别上路，裸奔被抓车扣住；等那铁牌挂好了，再踩油门再出发。

## ⑧ 使用别人号牌 / 假牌 / 套牌 —— 12 分 + 2000~5000 元 + 拘留

```
      🚗 大柱的车
   ┌─────────────┐
   │ 后窗：📋别人的牌│  ← 套了辆豪车的号
   │  （完全是假的） │
   └─────────────┘
         ↓
   ╔═══════════════════╗
   ║ 号牌造假，最狠！    ║  12分 + 2000~5000元
   ║ 还要拘留 ≤15天      ║  + 拘留！
   ╚═══════════════════╝
```

大柱干了件蠢事：把自己车的牌照换成了网上买的假牌，还套了辆保时捷的号，以为这样超速没人查得到。结果被大数据一比对，假牌当场露馅——不仅 12 分、罚款好几千，人还被拘留了。

> **后果**：使用伪造、变造号牌 / 套牌 = **扣 12 分 + 罚 2000~5000 元 + 拘留**，这是整套处罚里最重的之一。
>
> **口诀**：假牌套牌别碰它，十二分加拘留罚；省下保险那点钱，换来案底悔一辈子。

## 本类小结

```
号牌这件事，越动歪心思越重：

  歪着装   →  3 分
  故意遮挡  →  9 分
  根本没挂  →  9 分 + 扣车
  造假/套牌 →  12 分 + 拘留 💀

记住这条上升曲线，考试遇到选最重的那个就对了。
```
