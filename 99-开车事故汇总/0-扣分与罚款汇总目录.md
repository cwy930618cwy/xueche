# 扣分 + 罚款 汇总目录（从低到高，不说故事）

> 这是**纯目录 / 速查表**，把《记分分值违法行为》和《罚款金额全解》两篇的内容，**从最轻到最重**重新梳理一遍。
> 不讲故事，只列条目。考试前对着这张表扫一遍就够了。

---

## 总览：从轻到重的完整阶梯

```
   处罚由轻到重（往上爬）

   【罚款】20~200 → 200~500 → 200~2000 → 500~2000 → 1000~2000 → 2000~5000
   【记分】 1 分  →  3 分   →  6 分    →  9 分    →  12 分
                        （无对应）   （无对应）
```

> 注意：**罚款和记分不是完全对齐的**。有些行为只罚款不记分（如违停），有些既扣分又罚款。下面分开两张表，各自从低到高排。

---

# 第一部分　罚款（从低到高六档）

## ① 20 ~ 200 元（最轻 · 一般程序小违法）

| 行为 | 记几分 |
| --- | --- |
| 未随车携带驾驶证 | 不记分 |
| 未随车携带行驶证 | 不记分 |
| 未放置检验合格标志（年检标） | 不记分 |
| 未放置保险标志（交强险标） | 不记分 |
| 未按规定悬挂号牌 | 不记分 |
| 违规停车 | 不记分 |
| 未按规定使用安全带 | **记 1 分**（例外） |

> 关键词：**手续没带齐**。大多只罚钱不扣分，唯独"安全带"要额外记 1 分。

## ② 200 ~ 500 元（一般通行违法）

| 行为 | 记几分 |
| --- | --- |
| 违反禁令标志、禁止标线（压单行线、闯禁行区） | 记 1 分 |
| 不按规定车道行驶 | 记 1 分 |
| 不按规定超车、让行 | 记 1 分 |
| 超速行驶（未到 50%） | 记 1 分 |
| 货车闯禁行 | 记 1 分 |

> 关键词：**影响了秩序**。这一档都记 1 分。

## ③ 200 ~ 2000 元（较重违法）

| 行为 | 记几分 |
| --- | --- |
| 未取得驾驶证驾驶机动车（无证） | 不记分 |
| 饮酒后驾驶机动车（酒驾） | **记 12 分** |
| 造成交通事故后逃逸（不构成犯罪） | **记 12 分** |
| 货运机动车载物超过核定载质量（超载） | 记 3 / 9 分 |
| 超速 50% 以上 | **记 12 分** |
| 驾驶拼装的机动车 | — |

> 关键词：**危险又恶劣**。酒驾、逃逸、超速半倍直接记满 12 分。

## ④ 500 ~ 2000 元（坑人也要罚）

| 行为 | 记几分 |
| --- | --- |
| 将机动车交由未取得驾驶证的人驾驶 | 不记分（罚车主） |
| 将机动车交由驾驶证被暂扣/吊销的人驾驶 | 不记分 |
| 强迫、指使他人违章驾车造成事故 | — |
| 故意损毁、移动交通设施 | — |

> 关键词：**害别人一起违法**。罚的是车主/指使者。

## ⑤ 1000 ~ 2000 元（醉酒驾驶）

| 行为 | 记几分 |
| --- | --- |
| 醉酒驾驶机动车（血液酒精 ≥ 80mg/100ml） | **记 12 分** |

> 关键词：**喝醉了还开 = 犯罪**。吊证 5 年 + 追刑责。

## ⑥ 2000 ~ 5000 元（最狠 · 号牌造假）

| 行为 | 记几分 |
| --- | --- |
| 伪造、变造机动车号牌 | 不记分（直接拘留） |
| 伪造、变造行驶证、登记证书 | 不记分 |
| 使用伪造、变造的号牌/证件 | 不记分 |
| 使用其他车辆的号牌、行驶证（套牌） | 不记分 |
| 伪造、变造检验合格标志、保险标志 | 不记分 |

> 关键词：**动号牌心思**。不记分，但直接拘留 15 日以下 + 追究刑事责任。

# 第二部分　记分（从低到高五档）

## ① 一次记 1 分（轻微 · 小毛病）

| 行为 |
| --- |
| 不按规定使用灯光 |
| 不按规定使用安全带 |
| 违规载物（普通货车装载不规范） |
| 违反禁令标志、禁止标线（部分情形） |
| 摩托车不按规定载人 |

> 对应罚款：多为 **20 ~ 200 元**。

## ② 一次记 3 分（注意 · 分心/不规范）

| 行为 |
| --- |
| 驾驶机动车拨打、接听手持电话、吸烟等妨碍安全驾驶 |
| 摩托车驾驶人不按规定佩戴安全头盔 |
| 高速公路/快速路低于最低限速行驶 |
| 不按规定超车、让行，或普通道路逆行 |
| 人行横道不停车让行 |
| 不按规定安装号牌 |
| 载货长宽高超出规定（普通超限） |

> 对应罚款：多为 **200 元**。

## ③ 一次记 6 分（危险 · 明显违规）

| 行为 |
| --- |
| 闯红灯 / 不按信号灯通行 |
| 占用应急车道行驶或停车 |
| 不按规定避让校车 |
| 运载危险品不按规定悬挂标志、行驶 |
| 驾驶证暂扣期间驾车 |

> 对应罚款：多为 **200 元**；暂扣期间驾车为 200~2000 元。

## ④ 一次记 9 分（高危 · 大隐患）

| 行为 |
| --- |
| 准驾车型不符 |
| 载货超过核定载质量 50%~100%（货车超载） |
| 中型以上客车超员 20% 以上 |
| 故意遮挡、污损号牌 |
| 未悬挂机动车号牌上路 |
| 在高速公路、城市快速路上违法停车 |

> 对应罚款：多为 **200 元**；准驾不符、超载为 200~2000 元。

## ⑤ 一次记 12 分（要命 · 碰了就要回炉）

| 行为 |
| --- |
| 饮酒后驾驶机动车 |
| 造成交通事故后逃逸（尚不构成犯罪） |
| 超速 50% 以上 |
| 使用其他车辆号牌 / 伪造、变造号牌 |
| 驾驶与准驾车型不符的机动车（部分情形） |
| 在高速公路上倒车、逆行、穿越中央分隔带掉头 |
| 代替实际驾驶人接受记分和罚款（买卖分、顶包） |

> 对应罚款：多为 **200~2000 元**；醉驾 1000~2000 元。均暂扣/吊销驾照，可能拘留甚至入刑。

# 一句话规律

> **罚款**：二十两百手续缺 → 两百五百秩序裂 → 两千以下无证酒 → 五千以下假牌设。
> **记分**：一灯二盔三手机 → 六红应急不让校 → 九遮九超九停车 → 十二酒逃速半假。
> **总原则**：离"人命"越近，扣分越狠、罚款越多。
