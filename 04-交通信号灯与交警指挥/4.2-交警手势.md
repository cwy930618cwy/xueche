# 4.2 白手套的八种手势（看图版）

> 出场：刘建国（白手套·交警）、小雅（现场学）
> **怎么看这篇**：每种手势给你三样东西 —— ① **手臂表**（最清楚）② 简笔图 ③ 俯视图（谁能走）

---

## 先学会看简笔图

```
        ●          头
       ━┻━         肩（两臂从这里伸出）
        ┃          身体
       ╱ ╲         腿

   说明：交警是【面对你】站着的
        图上画在你【左边】的，是他的【右臂】
        图上画在你【右边】的，是他的【左臂】
```

---

## 手势一 · 停止信号

**① 手臂表**（最重要，看这个就够）

| 部位 | 动作 | 掌心 | 摆动 |
| --- | --- | --- | --- |
| **左臂** | 向**前上方**直伸（举起来） | 向前 | 不动 |
| **右臂** | 自然下垂 | — | 不动 |

**② 简笔图**

```
            ╱          ← 左臂向前上方举起来
           ╱
        ●━┻            ← 右臂垂着，不动
          ┃
         ╱ ╲
```

**③ 俯视图：谁要停？**

```
                 ↑ 对面（交警面对的方向）
                 │
              ✋ 停！
                 │
      ──────────●──────────   ← 交警
                 │
                 ↓ 你在这
```

**意思**：**不准前方车辆通行**（他正面对的那方向，全停）。

> 🔑 **口诀：一只手举高，全都给我停。**

---

## 手势二 · 直行信号

**① 手臂表**

| 部位 | 动作 | 掌心 | 摆动 |
| --- | --- | --- | --- |
| **左臂** | 向**左平伸** | 向前 | 不动 |
| **右臂** | 向**右平伸** | 向前 | **向左摆动** |

**② 简笔图**

```
        ●
       ━┻━          ← 两臂左右平伸，像"十字"
        ┃           右臂还要往里（左）摆
       ╱ ╲
```

**③ 俯视图：谁能走？**

```
                 ↑
                 │
      直行 ←─────●─────→ 直行
                 │
                 ↓
```

**意思**：准许**左右两方**直行的车辆通行。

> 🔑 **口诀：两手平伸像十字，直行车辆可以走。**

---

## 手势三 · 左转弯信号

**① 手臂表**

| 部位 | 动作 | 掌心 | 摆动 |
| --- | --- | --- | --- |
| **右臂** | 向**前平伸**（挡着） | 向前 | 不动 |
| **左臂** | — | 向右 | **向右前方摆动** |

**② 简笔图**

```
            ╲           ← 左臂往右前方摆
             ╲
        ●━━━━┻          ← 右臂向前平伸，挡住
              ┃
             ╱ ╲
```

**③ 俯视图**

```
                 ↑
                 │
      左转 ↙─────●
                 │
                 ↓
```

**意思**：准许**左方**车辆左转弯。

**怎么记**：**哪只手"前伸挡住"，另一只手摆动就放哪边走** → 右臂挡 + 左臂摆 = **左转**。

> 🔑 **口诀：右手前伸挡住路，左手一摆 —— 左边的车可以左转。**

---

## 手势四 · 左转弯待转信号

**① 手臂表**

| 部位 | 动作 | 掌心 | 摆动 |
| --- | --- | --- | --- |
| **左臂** | 向左**下方**平伸（斜下） | **向下** | **上下摆动** |
| **右臂** | 自然下垂 | — | 不动 |

**② 简笔图**

```
        ●
       ━┻
        ┃
       ╱            ← 左臂斜着伸向左下方
      ↕              掌心朝下，上下摆
```

**③ 意思**

```
   左转的车：开进路口中间【等着】
   （别停在路口外面，进去等信号）
```

**意思**：左方左转弯的车辆**进入路口等候**。

> 🔑 **口诀：左臂斜下掌心朝下上下摆 —— 左转的车先进路口等。**

---

## 手势五 · 右转弯信号

**① 手臂表**

| 部位 | 动作 | 掌心 | 摆动 |
| --- | --- | --- | --- |
| **左臂** | 向**前平伸**（挡着） | 向前 | 不动 |
| **右臂** | — | 向左 | **向左前方摆动** |

**② 简笔图**

```
            ╱           ← 左臂向前平伸，挡住
           ╱
        ●━┻━━━          ← 右臂往左前方摆
          ┃
         ╱ ╲
```

**③ 俯视图**

```
                 ↑
                 │
                 ●─────↘ 右转
                 │
                 ↓
```

**意思**：准许**右方**车辆右转弯。

**对比左转弯**：

```
   左转弯：右臂挡 + 左臂摆
   右转弯：左臂挡 + 右臂摆
   ─────────────────────────
   记住：【挡住的手】和【放行的方向】是反的
```

> 🔑 **口诀：左手前伸挡住路，右手一摆 —— 右边的车可以右转。**

---

## 手势六 · 变道信号

**① 手臂表**

| 部位 | 动作 | 掌心 | 摆动 |
| --- | --- | --- | --- |
| **右臂** | 向**前平伸** | **向左**（朝里） | **向左水平摆动** |
| **左臂** | 自然下垂 | — | 不动 |

**② 简笔图**

```
        ●
       ━┻━━━          ← 右臂前伸，掌心朝里
        ┃
        ←             往左一摆
       ╱ ╲
```

**③ 意思**

```
   你占的这条道 → 让出来（腾空）
   同时 → 减速慢行
```

**意思**：车辆应当**腾空指定的车道，减速慢行**。

> 🔑 **口诀：一只手前伸掌心朝里，往里一摆 —— 腾道、减速。**

---

**① 手臂表**

| 部位 | 动作 | 掌心 | 摆动 |
| --- | --- | --- | --- |
| **右臂** | 向**右前方**平伸 | **向下** | **向下摆动** |
| **左臂** | 自然下垂 | — | 不动 |

**② 简笔图**

```
        ●
       ━┻
        ┃ ╲          ← 右臂斜着伸向右前方
          ╲
           ↕          掌心朝下，上下摆
```

**③ 意思**：车辆**减速慢行**。

> 🔑 **口诀：掌心朝下上下摆 —— 减速慢行。**

---

## 手势八 · 靠边停车信号

**① 手臂表**

| 部位 | 动作 | 掌心 | 摆动 |
| --- | --- | --- | --- |
| **左臂** | 向**前上方**直伸（举高，同"停止"） | 向前 | 不动 |
| **右臂** | 向**前下方**平伸 | **向左** | **向左水平摆动** |

**② 简笔图**

```
            ╱          ← 左臂举高（和"停止"一样）
           ╱
        ●━┻
          ┃
          ╲            ← 右臂伸向前下方
           ←           往左摆
          ╱ ╲
```

**③ 意思**：车辆应当**靠边停车**。

> 🔑 **口诀：左手举高 + 右手在下面摆 —— 靠边停。**

---

## 三对最容易混的

### ① 停止 vs 靠边停车

```
   ┌────────────────┬────────────────┐
   │   停 止         │   靠边停车      │
   ├────────────────┼────────────────┤
   │  左臂举高       │  左臂举高       │
   │  右手【不动】   │  右手【在下摆】 │
   └────────────────┴────────────────┘

   👉 左手都一样，【看右手】：
      右手垂着不动 = 停止
      右手在下面摆 = 靠边停车
```

### ② 左转弯 vs 右转弯

```
   ┌────────────────┬────────────────┐
   │   左转弯        │   右转弯        │
   ├────────────────┼────────────────┤
   │  右臂前伸（挡） │  左臂前伸（挡） │
   │  左臂摆动       │  右臂摆动       │
   └────────────────┴────────────────┘

   👉 【哪只手前伸挡着】，放行的就是【另一边】
```

### ③ 减速慢行 vs 左转弯待转

```
   ┌────────────────┬────────────────┐
   │  减速慢行       │  左转弯待转     │
   ├────────────────┼────────────────┤
   │  用【右臂】     │  用【左臂】     │
   │  伸向【右前方】 │  伸向【左下方】 │
   │  掌心朝下       │  掌心朝下       │
   │  上下摆         │  上下摆         │
   └────────────────┴────────────────┘

   👉 都是"掌心朝下 + 上下摆"，区别在【哪只手、伸向哪】
      右手 → 减速慢行
      左手 → 左转弯待转
```

## 八种手势总表

| 手势 | 左臂 | 右臂 | 意思 |
| --- | --- | --- | --- |
| **停止** | 前上举，掌心向前 | 垂下不动 | 前方车辆停 |
| **直行** | 左平伸 | 右平伸 + 向左摆 | 左右两方直行 |
| **左转弯** | 向右前摆 | 前平伸（挡） | 左方左转 |
| **左转待转** | 左下方，掌心向下，上下摆 | 垂下 | 左转车进路口等 |
| **右转弯** | 前平伸（挡） | 向左前摆 | 右方右转 |
| **变道** | 垂下 | 前伸掌心向左，向左摆 | 腾道 + 减速 |
| **减速慢行** | 垂下 | 右前方，掌心向下，上下摆 | 减速慢行 |
| **靠边停车** | 前上举 | 前下方，掌心向左，向左摆 | 靠边停车 |

---

## 一句话总结

> **一只手举高 = 停；右手再往下摆 = 靠边停。**
> **两手平伸 = 直行；右挡左摆 = 左转，左挡右摆 = 右转。**
> **掌心朝下上下摆：右手是减速，左手是待转。**
> **一只手前伸掌心朝里往里摆 = 腾道减速。**
> **有交警，听交警，别看灯。**
