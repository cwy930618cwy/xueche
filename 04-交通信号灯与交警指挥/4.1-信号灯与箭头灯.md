# 4.1 故事：路口那盏灯

> 出场：小雅（新手）、老王、马三（抢黄灯）、豆豆（过马路）、刘建国（白手套）

---

## 第一幕 · 三种灯，三种意思

```
   ╭──────────╮
   │    ●     │   红灯 → 【停】禁止通行
   ├──────────┤
   │    ●     │   黄灯 → 【等】警示
   ├──────────┤
   │    ●     │   绿灯 → 【行】准许通行
   ╰──────────╯
```

老王带小雅到路口，指着灯："先记最基础的三个——"

| 灯 | 意思 | 小雅的话 |
| --- | --- | --- |
| **红灯** | **禁止通行** | "停死，一步都不能动" |
| **绿灯** | **准许通行** | "能走，但转弯得让直行和行人" |
| **黄灯** | **警示（过渡）** | "已经过线的继续走，没过线的必须停" |

> 🔑 **口诀：红灯停、绿灯行、黄灯亮了等一等。**

---

## 第二幕 · 黄灯到底能不能过？（最容易错）

马三开车冲到路口，灯变黄了，一脚油门冲过去。

```
   ╭─────────╮
   │ ██   ██ │
   │    ◡    │     马三：冲——
   ╰────┬────╯
```

差点撞上侧面已经起步的车。刘建国一挥白手套把他拦下。

### 黄灯的正确理解

```
   情况①：黄灯亮时，你的车【已经越过停止线】
           ↓
   ✅ 可以继续通行（别停在路口中间挡路）


   情况②：黄灯亮时，你的车【还没到停止线】
           ↓
   ❌ 必须停车等候，不能再往前冲
```

```
   图示
   ══════════════════════════════════
        🚗                    🚙
        │                     │
        │ 未过线              │ 已过线
        ↓                     ↓
      【停】                 【走】
```

老王："**黄灯不是'加速信号'，是'清空信号'** —— 它是让已经在路口里的车赶紧走完。"

> 🔑 **口诀：黄灯不是加速灯 —— 过线的赶紧走，没过线的必须停。**

---

## 第三幕 · 黄灯"持续闪烁"又是另一回事

小雅晚上回家，看到路口的黄灯**一直闪**（不是常亮）。

老王："这叫**黄灯闪烁**，和刚才的黄灯不是一回事。"

```
   黄灯常亮（3 秒过渡）        黄灯持续闪烁
   ┌──────────────┐         ┌──────────────┐
   │  警示：要变灯了 │         │  警示：路口没灯控 │
   │  过线走/没过停  │         │  减速瞭望、       │
   │               │         │  确保安全通过     │
   └──────────────┘         └──────────────┘
            ↑                        ↑
      正常信号灯的黄灯          深夜/车少路口的闪黄灯
```

"**闪黄灯的意思是：这个路口没有红绿灯控制，你自己看清楚再过。**"

> 🔑 **口诀：黄灯常亮等一等，黄灯闪烁慢慢走（瞭望确认再通过）。**

---

## 第四幕 · 箭头灯：它比圆灯"官大"

### 小雅吃了个罚单

小雅看到**圆圆的绿灯**亮了，直接右转，结果被拍。

```
   ╭──────────╮
   │    ●     │   ← 圆灯：绿
   │      ➜ ● │   ← 右转箭头：红 🔴
   ╰──────────╯
```

"**圆灯绿了，但右转箭头是红的 —— 你不能右转！**"

### 箭头灯的规矩

```
   ┌────────────────────────────────────┐
   │  绿色箭头 → 允许【按箭头方向】通行   │
   │  红色箭头 → 禁止【按箭头方向】通行   │
   │                                    │
   │  ⚠️ 优先级：【箭头灯 > 圆灯】        │
   │     两个都在时，听箭头灯的           │
   └────────────────────────────────────┘
```

```
   场景对照
   ┌──────────────────┬──────────────────┐
   │  圆灯绿 箭头红    │  圆灯红 箭头绿    │
   │  ─────────────   │  ─────────────   │
   │  ❌ 不能走        │  ✅ 可以按箭头走  │
   │  （箭头说了算）    │  （箭头开了绿灯）│
   └──────────────────┴──────────────────┘
```

> 🔑 **口诀：箭头灯比圆灯大，箭头红了就别动，箭头绿了就能走。**

---

## 第五幕 · 红灯能右转吗？（能，但有条件）

小雅："那**红灯的时候能右转**吗？"

老王："**能，但得看情况。**"

```
   情况①：只有圆灯，没有右转箭头
   ┌────────────────────────────────┐
   │  🔴 红灯亮着                     │
   │  右转车辆，在【不妨碍】被放行的   │
   │  车辆和行人通行的前提下          │
   │  ✅ 可以右转                     │
   └────────────────────────────────┘

   情况②：有右转箭头灯，且箭头是红的
   ┌────────────────────────────────┐
   │  🔴 右转箭头红                   │
   │  ❌ 不许右转，老实等着            │
   └────────────────────────────────┘
```

### 关键：要"让"

小雅要右转，正好豆豆在过人行横道。

```
     ╭─────╮
     │ ⊙ ⊙ │
     │  ‿  │     豆豆正在过斑马线
     ╰──┬──╯
```

老王一脚副刹："**停！让行人先过。** 红灯右转的前提是'不妨碍'，撞了行人你全责。"

> 🔑 **口诀：圆灯红灯能右转，但要先让行人和被放行的车；箭头红灯就别动。**

---

## 第六幕 · 车道灯：看自己头上那盏

有些路口上方，每条车道各有一盏灯。

```
   ┌────┐  ┌────┐  ┌────┐
   │ ↓  │  │ ✕  │  │ ↓  │
   │ 绿 │  │ 红 │  │ 绿 │
   └────┘  └────┘  └────┘
    车道1    车道2   车道3
    ✅能走   ❌禁行   ✅能走
```

- **绿色向下箭头** = 本车道**准许通行**
- **红色叉形 / 红色向下箭头** = 本车道**禁止通行**

> 🔑 **口诀：车道灯看自己头顶 —— 绿箭头走，红叉不许走。**

---

## 第七幕 · 人行横道灯、铁路道口灯

### 人行横道灯（豆豆看的）

```
   ┌────────┐
   │ 🚶 绿  │ → 行人可以过
   ├────────┤
   │ ✋ 红  │ → 禁止进入人行横道
   └────────┘
```

"**已经走到一半的行人，可以继续走完，也可以在道路中心线处等候** —— 别停在马路中间。"

### 铁路道口灯

```
   🚦🚦 两个红灯交替闪烁（或一个红灯亮）
        → 【禁止通行】，必须停在停止线外

   🚦 红灯熄灭
        → 允许通行
```

老王："**铁路道口红灯亮，宁可等，绝不抢。**"

> 🔑 **口诀：道口红灯亮，停车等火车；红灯灭了再走。**

## 第八幕 · 灯和交警打架了，听谁的？

小雅遇到一个情况：信号灯是绿灯，但刘建国站在路口**手势让她停**。

```
   ╔═════════╗
   ║ ⊙     ⊙ ║
   ║    ─    ║     刘建国：手一抬 —— 停！
   ╚════┬════╝
   〔白手套〕
```

"**听交警的。**"

```
   优先级
   ┌────────────────────────────┐
   │  ① 现场交警指挥  ← 最大     │
   │  ② 交通信号灯              │
   │  ③ 交通标志、标线           │
   └────────────────────────────┘
```

> **原因**：信号灯是固定的，交警是根据**实际路况**临时指挥的。堵车、事故、特殊任务时，灯不管用，人管用。

> 🔑 **口诀：灯是死的，人是活的 —— 有交警就听交警的。**

（交警的八种手势，下一篇 4.2 专门讲）

## 速查表

| 情形 | 怎么做 |
| --- | --- |
| 红灯 | 禁止通行（停在停止线外） |
| 绿灯 | 准许通行，**转弯不得妨碍直行车辆和行人** |
| 黄灯**常亮**，已越线 | **继续通过** |
| 黄灯**常亮**，未越线 | **停车等候** |
| 黄灯**持续闪烁** | 减速瞭望，确保安全通过 |
| 箭头绿灯 | 按箭头方向通行 |
| 箭头红灯 | 禁止按箭头方向通行 |
| **箭头灯与圆灯不一致** | **听箭头灯** |
| 圆灯红灯，无右转箭头 | 不妨碍他人时可**右转** |
| 右转箭头红灯 | **不许右转** |
| 车道灯红叉 | 本车道禁行 |
| 铁路道口红灯（闪） | 禁止通行 |
| 交警指挥与信号灯不一致 | **服从交警** |

---

## 一句话总结

> **红灯停、绿灯行、黄灯过线的走没过的停；闪黄灯是减速瞭望。**
> **箭头灯比圆灯大，箭头红了别动。**
> **圆灯红灯能右转，但要先让人；道口红灯绝不抢。**
> **有交警，听交警。**
