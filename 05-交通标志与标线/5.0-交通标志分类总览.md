# 5.0 交通标志 · 分类总览（七大类一次理清）

> 出场：老王、王小雅
> 交通标志国标里一共**七大类**。别被一堆标志吓到，**按"颜色 + 形状"就能归类**。
> 这篇是总纲，先建立框架，每类再单独展开（警告/禁令详见 5.1）。

---

## 七大类总览（先看这张，心里有框架）

| 类别 | 颜色 | 形状 | 一句话作用 |
| --- | --- | --- | --- |
| **① 警告标志** | **黄**底黑图案 | **三角形** | 前面有情况，**小心** |
| **② 禁令标志** | **白**底**红**圈 | **圆形** | **不许**这么干 |
| **③ 指示标志** | **蓝**底白图案 | 圆形/方形 | **告诉你怎么做**（直行、车道） |
| **④ 指路标志** | **蓝**底白字（高速**绿**） | **长方形** | **指方向、报地名** |
| **⑤ 旅游区标志** | **棕**底白图案 | 方形 | 指景点、名胜 |
| **⑥ 道路施工标志** | **橙**色为主 | 三角/方形 | 前方在修路 |
| **⑦ 辅助标志** | 白底黑字 | 小方块 | 给主标志**补充说明** |

> 🔑 **记颜色就够**：**黄警告、红禁止、蓝指示、绿指路、棕旅游、橙施工、白辅助** → 七色对七类。

---

## ① 警告标志（黄三角）—— 小心

```
              /\
             /  \     黄底、黑边、黑图案
            / !! \    等边三角形，顶角朝上
           /______\
```

- **作用**：提醒"前面有危险/情况"，**只警告、不禁止**。
- **常见**：注意行人、注意儿童、急弯路、连续下坡、注意落石、施工、隧道……
- 🔑 **口诀**：黄三角 = 警告 = 看见就减速观察。

> 详见 5.1。

---

## ② 禁令标志（红圈）—— 不许

```
           ______
         /        \
        |    ⊘     |   白底、红圈、红杠、黑图案
         \________/    圆形
```

- **作用**：**禁止或限制**某种行为（不许走、不许停、不许超……）。
- **常见**：禁止通行、禁止驶入、禁止左转、禁止停车、限速……
- **两个例外**：停车让行（八角形）、减速让行（倒三角）。
- 🔑 **口诀**：红圈 = 禁止 = 不许这么干。

> 详见 5.1。

---

## ③ 指示标志（蓝底）—— 告诉你怎么做

```
   ┌────────┐        ╭──────╮
   │  ↑↑↑   │        │  →   │   蓝底、白图案
   └────────┘        ╰──────╯   圆形或方形
   直行车道            允许右转
```

- **作用**：**指示**车辆/行人该怎么做（走哪条道、能往哪走）。
- **常见**：直行、左转、右转、步行、鸣喇叭、最低限速、车道方向……
- 🔑 **口诀**：蓝底白图 = 指示 = 照它做就对了。

> ⚠️ **易混**：指示标志（蓝）是"**让你走**"，禁令标志（红）是"**不让你走**"。

---

## ④ 指路标志（蓝底 / 高速绿底）—— 指方向

```
   普通路：┌──────────────┐   蓝底白字
           │  人民路  2km │   长方形
           └──────────────┘

   高速：  ┌──────────────┐   绿底白字
           │  南京  128km │   长方形
           └──────────────┘
```

- **作用**：**传递方向、地点、距离**信息，帮你找路。
- **常见**：地名、方向箭头、出口预告、服务区、距离确认……
- **颜色区别**：**普通道路蓝底，高速公路绿底**。
- 🔑 **口诀**：蓝绿长方块 = 指路 = 看它找方向。

---

## ⑤ 旅游区标志（棕底）—— 指景点

```
   ┌──────────────┐
   │   🏛 故宫     │   棕底、白图案、白字
   │    5km →     │   方形
   └──────────────┘
```

- **作用**：指示**旅游景点、名胜**的方向和距离。
- 🔑 **口诀**：棕底白图 = 旅游 = 奔景点去。

---

## ⑥ 道路施工安全标志（橙色）—— 前方修路

```
        /\
       /  \     橙色为主
      / 工人 \   三角或方形
     /________\
```

- **作用**：提示**前方道路施工、养护**，注意安全。
- 🔑 **口诀**：橙色标志 = 施工 = 减速慢行。

---

## ⑦ 辅助标志（小白块）—— 补充说明

```
   主标志（大）
   ┌────────┐
   │  ⊘ 禁行 │
   └────────┘
   ┌────────┐
   │ 7:00-   │  ← 辅助标志（小方块）
   │ 19:00   │     补充时间/范围
   └────────┘
```

- **作用**：附在主标志下面，**补充说明时间、范围、原因**等。
- 🔑 **口诀**：小方块在下方 = 辅助 = 给上面那块补充条件。

---

## 七色速记图（考前扫一眼）

```
   黄 → 警告     （三角，小心）
   红 → 禁令     （圆，不许）
   蓝 → 指示     （告诉你怎么做）
   蓝/绿 → 指路  （普通蓝、高速绿，找方向）
   棕 → 旅游     （指景点）
   橙 → 施工     （前方修路）
   白 → 辅助     （补充说明）
```

> 🔑 **总口诀**：
> **黄警红禁蓝指示，绿指路棕旅游，橙色施工白辅助，七色记牢不乱套。**

---

## 一句话总结

> 交通标志七大类，**看颜色就分得清**：
> **黄三角警告、红圈禁止、蓝底指示、蓝绿指路、棕旅游、橙施工、白辅助。**
> 先认颜色定大类，再看图案懂意思。
