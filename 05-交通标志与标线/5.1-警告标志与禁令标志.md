# 5.1 警告标志 与 禁令标志

> 出场：老王、小雅
> 这一篇只讲**两类**：黄三角的**警告**标志、红圈的**禁令**标志。

---

## 一、警告标志（黄三角）

### 长什么样

```
              /\               黄底
             /  \              黑边
            / !! \             黑图案
           /______\

      等边三角形，顶角【朝上】
```

### 它在说什么

"**前面有情况，小心！**" —— 只**提醒**，不禁止。

| 要素 | 内容 |
| --- | --- |
| 颜色 | **黄底、黑边、黑图案** |
| 形状 | **等边三角形**（顶角朝上） |
| 作用 | 警告车辆、行人注意危险地点 |

### 常见的警告标志

```
   △ 十字交叉路口    △ T形交叉     △ 急弯路    △ 连续弯路
   △ 上陡坡/下陡坡   △ 连续下坡    △ 窄路窄桥  △ 双向交通
   △ 注意行人        △ 注意儿童    △ 注意牲畜  △ 注意落石
   △ 注意横风        △ 易滑路面    △ 傍山险路  △ 村庄
   △ 隧道            △ 驼峰桥      △ 路面不平  △ 过水路面
   △ 事故易发路段    △ 施工        △ 注意非机动车 △ 注意危险
```

**场景**：老王开到村口，路边立着个黄三角画着小人 —— "**注意行人**，前面村子，豆豆他们随时跑出来，减速。"

> ⚠️ 记住：**"十字交叉路口"是警告标志**（黄三角），不是指路标志。

> 🔑 **口诀：黄底黑边三角形 = 警告；看见就减速、观察。**

## 二、禁令标志（红圈）

### 长什么样

```
           ______
         /        \
        /          \       白底
       |     ⊘      |      红圈 + 红杠
        \          /       黑图案（压在红杠上）
         \________/
```

### 它在说什么

"**不许干！**" —— 禁止或限制某种行为。

| 要素 | 内容 |
| --- | --- |
| 颜色 | **白底、红圈、红杠、黑图案** |
| 形状 | **圆形**（两个例外见下） |
| 作用 | 禁止或限制车辆、行人的交通行为 |

### 常见的禁令标志

```
   ⊘ 禁止通行        ⊘ 禁止驶入      ⊘ 禁止机动车通行
   ⊘ 禁止左转        ⊘ 禁止右转      ⊘ 禁止直行
   ⊘ 禁止掉头        ⊘ 禁止超车      ⊘ 解除禁止超车
   ⊘ 禁止停车        ⊘ 禁止长时停车  ⊘ 禁止鸣喇叭
   ⊘ 限制速度（限速） ⊘ 解除限速      ⊘ 限制高度/宽度/质量
```

### 两个"不是圆形"的禁令标志（必考）

```
   ┌─────────────────┐      ┌─────────────────┐
   │   停 车 让 行    │      │   减 速 让 行    │
   │                 │      │                 │
   │       ┌──┐      │      │    ╲________╱   │
   │    ┌──┘  └──┐   │      │     ╲      ╱    │
   │    │   停   │   │      │      ╲    ╱     │
   │    └──┐  ┌──┘   │      │       ╲  ╱      │
   │       └──┘      │      │        ╲╱       │
   │                 │      │                 │
   │   【八角形】     │      │   【倒三角形】   │
   │   红底白字"停"  │      │   白底红边"让"  │
   └─────────────────┘      └─────────────────┘
          ↕                        ↕
   必须【停死】再走          必须【减速让行】
```

> 🔑 **口诀：八角"停"要停死，倒三角"让"要让行。**

## 三、两组最容易混的

### ① 禁止通行 vs 禁止驶入

```
   ┌─────────────┐         ┌─────────────┐
   │    ╭───╮    │         │    ╭───╮    │
   │   │     │   │         │   │ ── │   │
   │   │ 空白│   │         │   │白杠│   │
   │   │     │   │         │   │    │   │
   │    ╰───╯    │         │    ╰───╯    │
   │  白底红圈    │         │ 白底红圈+白横杠│
   └─────────────┘         └─────────────┘
        ↕                        ↕
   【禁止通行】              【禁止驶入】
   车辆行人都不许过          只禁止车辆进入
   （最严格）                （人还可以进）
```

> 🔑 **口诀：空圈是"禁止通行"（谁都不许过），加道杠是"禁止驶入"（车不许进）。**

### ② 禁止停车 vs 禁止长时停车

```
   ┌─────────────┐         ┌─────────────┐
   │    ╭───╮    │         │    ╭───╮    │
   │   │  ✕ │   │         │   │ ╲  │   │
   │   │    │   │         │   │  ╲ │   │
   │    ╰───╯    │         │    ╰───╯    │
   │  红圈里一个叉 │         │ 红圈里一道斜杠│
   └─────────────┘         └─────────────┘
        ↕                        ↕
   【禁止停车】              【禁止长时停车】
   一秒都不能停              可以临时停（上下人、装卸）
   停了就罚                 但司机不能离车
```

> 🔑 **口诀：画叉 = 完全禁停；画斜杠 = 禁长停（能临时上下人）。**

## 四、速查表

| | **警告标志** | **禁令标志** |
| --- | --- | --- |
| 颜色 | **黄底黑边黑图案** | **白底红圈红杠黑图案** |
| 形状 | **三角形**（顶角朝上） | **圆形**（停车让行八角、减速让行倒三角） |
| 语气 | "小心" | "不许" |
| 例子 | 注意行人、急弯路、施工 | 禁止通行、禁止左转、限速 |

---

## 一句话总结

> **黄三角 = 警告 = 前面小心（减速观察）。**
> **红圈 = 禁止 = 不许这么干（八角停死、倒三角让行）。**
> **空圈禁通行、加杠禁驶入；画叉全禁停、斜杠禁长停。**
