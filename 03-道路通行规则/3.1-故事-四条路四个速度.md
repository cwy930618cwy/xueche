# 3.1 故事：一天开了四条路，四个速度

> 这一篇只记四个数字：**30、40、50、70**。
> 跟着老王和小雅开一天车，四条路走一遍，就再也忘不掉了。
> 出场：老王、小雅、豆豆（小豆丁）、赵大爷（三轮太爷）

---

## 开场 · 周末练车

```
   ╲       ╱                    ╭─────────╮
  ╭─────────╮                  │ ⊖  ⊙  ⊖ │
  │ ◕     ◕ │                  │    ‿    │
  │    ‿    │                  ╰────┬────╯
  ╰────┬────╯                    ／ │ ＼
    ／ │ ＼                      ☕ ─┘
   小雅（练车）                   老王（副驾）
```

小雅："爸，路上没限速牌的时候，我到底能开多快？"

老王："**今天带你走四条路，走完你就懂了。**"

---

## 第一站 · 县城老巷子（城市 + 没有中心线）= **30**

```
   ┌────────────────────────────────┐
   │  墙                        墙   │
   │  ██                        ██  │
   │  ██   ←车→    ←车→        ██  │   中间【一根线都没有】
   │  ██                        ██  │
   └────────────────────────────────┘
        城市道路 + 没有中心线 = 30 km/h
```

小雅开到 45，老王一脚副刹："**停！这条巷子最多 30。**"

正说着，小学生豆豆从巷子口窜出来追皮球。

```
     ╭─────╮
     │ ⊙ ⊙ │
     │  ‿  │     豆豆：哇——
     ╰──┬──╯
      ／│＼
```

老王："**看见没？城里巷子，两边是墙、中间没线，随时窜出小孩，30 都嫌快。**"

> 🔑 **口诀：城里没线，三十为限。**

---

## 第二站 · 出城的乡间小路（公路 + 没有中心线）= **40**

出了城，路宽了一点，但中间还是没画线。

```
   ┌──────────────────────────────────────┐
   │  树                              树   │
   │  ♣      ←车→        ←车→          ♣  │   还是【没有中心线】
   │                                      │
   └──────────────────────────────────────┘
        公路 + 没有中心线 = 40 km/h
```

小雅："这总能快了吧？"

老王："**可以到 40** —— 比城里多了 10。为啥？**人少了、树多了，但还是没画线**，对向的车可能借道，所以不能太快。"

迎面赵大爷骑着三轮过来，慢悠悠占了大半个路面。

```
       ┌───────────┐
       │  带篷车厢  │
       └─────┬─────┘     赵大爷（三轮太爷）
            / \
         (O) (O)(O)
```

> 🔑 **口诀：城外没线，四十为限。**

---

## 第三站 · 城里主干道（城市 + 同向一条车道）= **50**

回到城里，上了主干道——**中间画了中心线**，但**小雅这个方向只有一条机动车道**。

```
   ┌────────────────────────────────────────┐
   │  ─ ─ ─ ─ ─  中心线  ─ ─ ─ ─ ─ ─ ─ ─   │
   │    ← 车 →  ← 车 →   （同向一条道）      │
   │  ══════════════════════════════════    │
   └────────────────────────────────────────┘
        城市道路 + 同向 1 条机动车道 = 50 km/h
```

老王："**有中心线了，路规矩了，可以到 50。**"

"但记住，这是**城里**——路口多、电动车多、行人多，所以比城外慢。"

> 🔑 **口诀：城里一道，五十正好。**

---

## 第四站 · 城外省道（公路 + 同向一条车道）= **70**

最后上了省道：有中心线，同向一条道，两边是田野。

```
   ┌────────────────────────────────────────┐
   │  ~~~~~~~  田 野  ~~~~~~~~~~~~~~~~~~~   │
   │  ─ ─ ─ ─ ─  中心线  ─ ─ ─ ─ ─ ─ ─ ─   │
   │    ←  车  →      ←  车  →              │
   │  ══════════════════════════════════    │
   └────────────────────────────────────────┘
        公路 + 同向 1 条机动车道 = 70 km/h
```

小雅："这条路好爽！"

老王："**最多 70。** 四条路里就属它最快——**路好、人少、有中心线**。"

> 🔑 **口诀：城外一道，七十最高。**

---

## 收尾 · 老王画的阶梯图

回家后，老王在纸上画了张图：

```
   路越好 → 速度越高

   ④ 公路 · 一道   70   ← 最快（人少 + 有线）
        │
   ③ 城市 · 一道   50
        │
   ② 公路 · 没线   40
        │
   ① 城市 · 没线   30   ← 最慢（人多 + 没线）
```

**两个判断维度**（小雅总结的）：

```
   ┌────────────────────────────────────┐
   │  维度①：城里 还是 城外？            │
   │         城里【慢】  城外【快】       │
   │                                    │
   │  维度②：有没有中心线？              │
   │         没线【慢】  有道【快】       │
   └────────────────────────────────────┘

   判断流程：
   先问：城里还是城外？
   再问：中间有没有线？
   → 两个答案一拼，速度就出来了
```

> 🔑 **总口诀：城里慢、城外快；没线慢、有线快 —— 三十、四十、五十、七十。**

---

## 为什么城市比公路慢？

小雅："同样是没线，凭啥城里 30、城外 40？"

老王："因为**城里危险多**："

```
   城里：行人多 ☂  电动车多 🛵  路口多 ✚  商铺多 🏪
   城外：人少、路口少、视野好

   → 同样的路，城里就得再慢一档
```

---

## 速查表

| 路长什么样 | 城市道路 | 公路 |
| --- | --- | --- |
| **中间没有中心线**（最破最窄） | **30** | **40** |
| **同方向只有 1 条机动车道**（有中心线） | **50** | **70** |

| 判断问题 | 答案 |
| --- | --- |
| 中间一根线都没有？ | 走"没线"那档（30 / 40） |
| 有中心线但同向只有一条道？ | 走"一道"那档（50 / 70） |
| 在城里还是在城外？ | 城里取小值，城外取大值 |

---

## 一句话总结

> **四条路四个数：城里没线三十、城外没线四十、城里一道五十、城外一道七十。**
> **记不住就问两句：城里还是城外？中间有没有线？—— 城里慢、没线慢。**
