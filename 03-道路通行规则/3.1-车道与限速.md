# 3.1 故事：路怎么分、车开多快

> 这一篇讲两件事：**哪条道归谁走**、**没有限速牌时该开多快**。
> 出场：老王（正确示范）、小雅（犯错）、王大柱（大货）、王小龙（摩托）、李红梅（公交）、马三（乱变道）、刘建国（白手套）

---

## 第一部分 · 车道划分与各行其道

### 第一幕 · 老王上了一条三车道的路

```
        【 同向 3 条机动车道 】

  ┌─────────┬─────────┬─────────┐
  │ 最左侧   │  中间    │ 最右侧   │
  │ 【快车道】│         │【慢车道】│
  │  小客车  │ 小客车   │ 大货/客车 │
  │         │  客车    │ 摩托车    │
  │ 最低 110 │ 最低 90  │ 最低 60   │（高速上的数字）
  └─────────┴─────────┴─────────┘
       ↑                     ↑
    跑得快的走这          跑得慢的、大车走这
```

老王握着方向盘给小雅讲：

- **最左侧 = 快速车道**：跑得快的小客车走这儿，**没达到快车道速度的，不许占着**
- **中间**：小客车、客车
- **最右侧 = 慢速车道**：大货车、大客车、摩托车走这儿

### 大柱该走哪条？

```
    ______      ┌────────────┐
   |  __  |     │            │
   | |  | |_____│   货厢     │     王大柱的 B2 大货
   |_|__|_|     └────────────┘
```

大柱开大货，速度上不去，**只能在最右侧慢车道**。他要超车，可以临时借用左边的快车道，**超完必须驶回右边**。

```
   慢车道超车规则
   ① 在右侧慢车道跟车
   ② 借左侧快车道超车
   ③ 超完【驶回原车道】 ← 不能一直占着快车道
```

> 🔑 **口诀：快左慢右各走各，大车摩托靠最右；超车可以借左道，超完必须回右道。**

### 摩托车必须在最右侧

王小龙骑摩托上来了，老王喊住他：

```
   ╭─────────╮
   │◖ ⊙   ⊙ ◗│
   │    ‿    │     王小龙（两轮小飞）
   ╰────┬────╯
   〔摩托车〕
```

"**摩托车应当在最右侧车道行驶。** 你别窜到中间去，人家看不见你。"

> 🔑 **口诀：摩托车，最右道，别往中间凑热闹。**

### 公交专用道（李红梅的地盘）

```
   ┌──────────────────────────────┐
   │  ▓▓▓ 公交专用道 ▓▓▓ │  其他车道  │
   │  只有公交车能走      │           │
   └──────────────────────────────┘
```

李红梅开公交走专用道：**合法**。
马三开着私家车图快钻进公交道：**违法**（罚款 + 记分）。

> 🔑 **口诀：专用车道专车走，私家车进去就挨罚。**

### 马三的"连续变道"

马三嫌前面慢，一把方向从最右连跨两条道到最左。

```
   马三的操作：
   最右 ──╲
          ╲──→ 中间 ──╲
                      ╲──→ 最左
   ❌ 一次连续变更两条以上车道
```

刘建国一挥白手套拦下："**一次只能变更一条车道，不得连续变更两条以上。** 你这样后面的车根本反应不过来。"

正确做法：

```
   ① 打转向灯
   ② 观察后视镜
   ③ 变一条道
   ④ 行驶一段，确认安全
   ⑤ 再变下一条
```

> 🔑 **口诀：变道先打灯，一次只变一条；连续跨两条，等着被拦下。**

## 第二部分 · 限速：没牌子的时候开多快

### 第一幕 · 小雅的疑问

> 四个数字记不住？看故事版 👉 [3.1-故事-四条路四个速度.md](./3.1-故事-四条路四个速度.md)
> （一天开四条路：城里没线 30、城外没线 40、城里一道 50、城外一道 70）

小雅："路上没限速牌，那我开多少都行？"

老王："**不行，没牌子也有规定。** 记住这两张图。"

### 图一：没有道路中心线的路（窄路）

```
   ┌────────────────────────────┐
   │                            │
   │    ←  车  →      ← 车 →    │   中间【没有】中心线
   │                            │   （窄路、乡间小路）
   └────────────────────────────┘

   城市道路：30 km/h
   公    路：40 km/h
```

> **场景**：小雅在县城老巷子里（没有中心线）开到 50 —— 老王一脚副刹："这路最多 **30**！"

### 图二：同方向只有 1 条机动车道的路

```
   ┌──────────────────────────────────┐
   │  ─ ─ ─ ─  中心线  ─ ─ ─ ─        │
   │    ←  车  →                      │   同向【只有 1 条】车道
   │  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─   │
   └──────────────────────────────────┘

   城市道路：50 km/h
   公    路：70 km/h
```

> **场景**：老王在县城外的省道上（同向一条道）开 70 —— "**公路 70**，合规。"

### 限速总表

| 道路情况 | 城市道路 | 公路 |
| --- | --- | --- |
| **没有道路中心线** | **30 km/h** | **40 km/h** |
| **同方向只有 1 条机动车道** | **50 km/h** | **70 km/h** |

> 🔑 **口诀：无中心线 —— 城三十、公四十；一条车道 —— 城五十、公七十。**

---

### 第二幕 · 一律 30 的"五种情形"

老王："还有几种情况，**不管什么路，统统不能超过 30**。"

```
   ┌────────────────────────────────────────┐
   │           最高 30 km/h 的情形            │
   ├────────────────────────────────────────┤
   │  ① 进出非机动车道、通过铁路道口、       │
   │     急弯路、窄路、窄桥                   │
   │  ② 掉头、转弯、下陡坡                    │
   │  ③ 雾雨雪沙尘冰雹，能见度 50 米以内     │
   │  ④ 在冰雪、泥泞的道路上行驶              │
   │  ⑤ 牵引发生故障的机动车                  │
   ├────────────────────────────────────────┤
   │  拖拉机、电瓶车、轮式专用机械车：15 km/h │
   └────────────────────────────────────────┘
```

```
   场景图示
   ┌──────┐              ╲╲            ┌──────┐
   │铁路道口│  → 30       ╲╲ 下陡坡     │ 窄 桥 │ → 30
   └──────┘               ╲╲  → 30     └──────┘

        ☂ 雨雪雾 能见度<50m → 30
        ❄ 冰雪泥泞 → 30
        🚗🚗 牵引故障车 → 30
```

> 🔑 **口诀：转弯掉头下陡坡、铁路道口窄桥过、能见不足五十米、冰雪泥泞拖故障 —— 统统三十。**

### 第三幕 · 超速的代价（预告）

小雅："超速了会怎样？"

老王："**超速越多，罚得越狠**——"

```
   超速 10% 以内   → 警告为主
   超速 10%~20%    → 罚款
   超速 20%~50%    → 罚款 + 记分（小车 3 分）
   超速 50% 以上   → 罚款 + 重记分，严重的可以吊销驾照
```

> 详细的记分分值放在**第七章**讲，这里先记住：**超速 50% 以上是最狠的一档。**

> 🔑 **口诀：超速超过一半，性质就变了 —— 不是罚款那么简单。**

## 速查表

| 项目 | 规定 |
| --- | --- |
| 同向多车道 | 左快右慢；**摩托车最右侧** |
| 慢车道超车 | 可借快车道，**超完驶回** |
| 变道 | **一次只能变一条**，不得连续变两条以上 |
| 专用车道 | 只准许规定车辆通行 |
| 无中心线道路 | 城市 **30** / 公路 **40** |
| 同向 1 条车道 | 城市 **50** / 公路 **70** |
| 特殊情形（5 种） | **一律 30**（拖拉机/电瓶车/轮式机械车 **15**） |
| 高速最高 / 最低 | **120 / 60** |

## 一句话总结

> **快左慢右、摩托最右、专用道专车走；变道一次一条，别连跨。**
> **没中心线：城三十公四十；一条车道：城五十公七十。**
> **转弯掉头下陡坡、铁路道口窄桥、能见度不到五十米、冰雪泥泞拖故障 —— 一律三十。**
