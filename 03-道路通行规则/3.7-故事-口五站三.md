# 3.7 故事："口五站三" —— 哪儿不能停车

> 驾考最经典的四个字：**口五站三**。
> 出场：马三（乱停车）、李红梅（公交车进不了站）、刘建国（贴条）、老王、小雅、吴医生

---

## 开场 · 马三被贴条了

```
   ╭─────────╮
   │ ██   ██ │
   │    ◡    │     马三（加塞王）
   ╰────┬────╯
     ／ │ ＼
   〔罚单〕
```

马三把车往路边一停，去买包子。回来发现车窗上多了张纸。

```
   ╔═════════╗
   ║ ⊙     ⊙ ║
   ║    ─    ║     刘建国（白手套）
   ╚════┬════╝
   〔白手套一挥〕
```

"这也能贴？我又没停在路中间！"

老王在旁边摇头："**有些地方，50 米、30 米之内都不许停。**"

---

## 第一幕 · 什么是"口五站三"

```
   ┌──────────────────────────────────────────────┐
   │                                              │
   │  【口 五】                    【站 三】        │
   │   这些地方 50 米内禁停         这些地方 30 米内禁停│
   │  ─────────────────          ─────────────────│
   │   交叉路口                    公共汽车站        │
   │   铁路道口                    急救站            │
   │   急弯路                      加油站            │
   │   窄路（宽度不足 4 米）        消防栓/消防队门前 │
   │   桥梁                                        │
   │   陡坡                                        │
   │   隧道                                        │
   └──────────────────────────────────────────────┘
```

**一个字概括**：
- **"口"** = 路口、道口、弯路、窄路、桥、坡、隧道 → **50 米**
- **"站"** = 公交站、急救站、加油站、消防站 → **30 米**

> 🔑 **口诀：口 五 站 三 —— 路口五十，站前三十。**

---

## 第二幕 · 故事一：马三堵了公交站（站三）

马三把车停在公交站**前面 10 米**的地方买早餐。

```
   ┌────────────────────────────────────┐
   │                                    │
   │   🚗 马三的车                        │
   │   ▭▭                               │
   │        ← 10 米 →                   │
   │              🚌 公交站牌             │
   │   ═══════════════════════════════  │
   │                                    │
   └────────────────────────────────────┘
         ❌ 30 米内禁停
```

李红梅开着公交车来了，进不去站：

```
   ╭─────────╮
  )│ ⊙     ⊙ │(     李红梅（三门官）
   │    ‿    │
   ╰────┬────╯
   〔公交喇叭：嘀——〕
```

"**你占了我的站位，我只能停在机动车道上下客，一车人冒着危险上下车。**"

刘建国走过来："**公交站 30 米以内不许停**，罚款 + 记分。"

> 🔑 **口诀：公交站前三十米，停了公交进不来。**

---

## 第三幕 · 故事二：小雅停在加油站门口（站三）

小雅开车到加油站附近，把车停在**加油站出入口 20 米处**等老王。

```
   ┌──────────────────────────────┐
   │   ⛽ 加 油 站                  │
   │   ┌────┐                     │
   │   │油机│                     │
   │   └────┘                     │
   │      ↑                       │
   │      │ ← 20 米               │
   │   🚗 小雅的车                  │
   └──────────────────────────────┘
         ❌ 30 米内禁停
```

老王："**加油站出入口 30 米内不能停** —— 加油的车进不去，你也堵了消防通道。"

> ⚠️ 例外：**你要是真进去加油，当然可以停**。规定禁止的是"停在 30 米内但不使用这个设施"。

> 🔑 **口诀：加油站前三十米，加油的可以进，等人的不行。**

---

## 第四幕 · 故事三：马三堵了路口（口五）

马三接电话，把车停在**十字路口 20 米处**。

```
                    ↑ 北
                    │
        ────────────╋────────────  ← 交叉路口
                    │
        🚗 20 米    │
       马三的车 ←───┘
```

结果：右转的车全被堵住，一个绿灯只过了两辆车。

刘建国："**交叉路口 50 米以内不许停车**，这是'口五'。"

> 🔑 **口诀：路口五十米内别停，你停一分钟，堵一条街。**

---

## 第五幕 · 故事四：铁路道口（口五）

老王讲了个真事：

```
   ════╤═══╤═══╤═══  铁轨
       │   │   │
   ────┴───┴───┴───  道路
        ↑
   铁路道口
```

"**铁路道口 50 米内一律不许停。** 以前有辆车坏在道口里，火车来了……"

"**所以过铁路道口，宁可等，也不要停在道口里面。**"

> 🔑 **口诀：铁路道口五十米，宁停三分，不抢一秒。**

---

## 第六幕 · 故事五：急救站门口（站三）

吴医生从急诊科冲出来：

```
   ╭─────────╮
   │ ⊙     ⊙ │
   │    ‿    │     吴医生（快刀吴）
   ╰────┬────╯
     ／ ✚ ＼
```

"**上个月有辆车停在我们急救站门口，救护车出不去，晚了四分钟。**"

```
   ┌──────────────────────────────┐
   │  ✚ 急 救 站                   │
   │  ┌──────┐                    │
   │  │救护车│                    │
   │  └──────┘                    │
   │      ↑                       │
   │      │ ← 30 米               │
   └──────────────────────────────┘
         ❌ 禁停（急救站、消防站同理）
```

> 🔑 **口诀：急救站、消防队，门前三十米不能睡 —— 那是救命的通道。**

---

## 第七幕 · 为什么"口"是 50、"站"是 30？

小雅："凭啥路口要 50 米，站牌只要 30 米？"

老王画了个图：

```
   【口 五】为什么远？
   路口 / 弯道 / 桥 / 坡 / 隧道
   → 这些地方【看不见、躲不开】
   → 你得给后车留出【反应距离】
   → 所以要 50 米

   【站 三】为什么近？
   公交站 / 加油站 / 急救站 / 消防站
   → 这些是【特定出入口】
   → 只需要留出【进出的空间】
   → 所以 30 米就够
```

> 🔑 **口诀：看不见的地方留五十，要进门的地方留三十。**

---

## 第八幕 · 顺便：临时停车的四条规矩

老王："就算能停的地方，**临时停车也有规矩**："

```
   ┌────────────────────────────────────────┐
   │  ① 紧靠道路【右侧】停放                  │
   │  ② 驾驶人【不得离车】                    │
   │  ③ 上下人 / 装卸物品后【立即驶离】        │
   │  ④ 开关车门【不得妨碍】其他车辆和行人     │
   └────────────────────────────────────────┘
```

**绝对不能停的地方**（不管几米）：

```
   ❌ 有禁停标志、标线的路段
   ❌ 有隔离设施的路段（机动车道和非机动车道之间）
   ❌ 人行横道、施工地段
   ❌ 黄网格（网状线）区域
   ❌ 高速公路行车道（应急车道除外，且仅限故障）
```

### 开车门的惨剧

老王讲了"开门杀"：

```
   🚗 ───→ 车门突然打开
              🚴 电动车撞上来
```

"**停车开车门前，先看后视镜，用远离车门的那只手开门**（荷式开门法）—— 这样身体会自然转过去看后面。"

> 🔑 **口诀：临时停车靠右、人不离车、即停即走；开门先看镜。**

## 速查表

| 类型 | 距离 | 包含哪些地点 |
| --- | --- | --- |
| **口 五** | **50 米**内禁停 | 交叉路口、铁路道口、急弯路、窄路（宽<4 米）、桥梁、陡坡、隧道 |
| **站 三** | **30 米**内禁停 | 公共汽车站、急救站、加油站、消防栓 / 消防队（站）门前 |
| 绝对禁停 | — | 禁停标志标线路段、隔离设施路段、人行横道、施工地段、网状线、高速行车道 |

| 临时停车 | 要求 |
| --- | --- |
| 位置 | 紧靠道路右侧 |
| 驾驶人 | 不得离车 |
| 时间 | 上下人 / 装卸后立即驶离 |
| 车门 | 开关不得妨碍他人 |

---

## 一句话总结

> **口五站三：路口弯道桥坡隧道五十米，公交站加油站急救站消防站三十米。**
> **看不见的地方留五十，要进门的地方留三十。**
> **临时停车：靠右、人不离车、即停即走，开门先看镜。**
