# 七、记分分值与违法行为（讲故事）

> 这一篇只讲一件事：**哪种违章扣几分。**
> 上一篇文章讲了"分怎么扣、满了怎么办"，这篇把**每一分对应哪些行为**讲清楚。
> 记住一句话：**越危险、越恶劣的行为，扣得越狠。**
> 出场：王小雅（两踏板，负责犯错）、王大山（老王，正确示范）、刘建国（白手套·交警）、王大柱（大力士 B2）、王小龙（两轮小飞 E）

> 🔑 **一眼看懂的规律**：
> - **12 分档**：罚款最重，都是 **200~2000 元起步**，醉驾更是 **1000~2000 元 + 吊证**。
> - **9 分、6 分、3 分档**：大多是固定 **200 元**，超载、准驾不符这类重的才到 **200~2000 元**。
> - **1 分档**：都是小毛病，**20~200 元**封顶。
> - **一句话：扣的分越高，罚的钱越多——12 分档动辄上千，1 分档最多两百。**

### 三条判断标准（一条违章落到哪档，就问这三个问题）

**① 会不会直接要命？→ 决定 12 分**

```
   酒驾 → 反应迟钝，撞人躲不开      ┐
   逃逸 → 伤者得不到救助，死亡率飙升 │ → 都跟"人命"挂钩 → 12 分
   高速逆行 → 正面相撞，必出大事     ┘
```
共同点：行为人**明知危险还去做**，一旦出事后果极严重。所以顶格 12 分，暂扣驾照、回炉重考。

**② 是不是"大隐患"？→ 决定 9 分**

```
   超载 → 刹车距离变长，爆胎翻车
   准驾不符 → 不会开这种车，操控失控   → 车或驾驶人有大问题 → 9 分
   遮挡号牌 → 逃避查处，出事找不到人
   高速停车 → 后车追尾，连环死亡
```
不一定马上出事，但**隐患很明显**，属于"迟早要出事"的状态。

**③ 是主动违规，还是小疏忽？→ 决定 6 / 3 / 1 分**

```
   闯红灯 → 主动违反信号，路口冲突    → 明显主动违规 → 6 分
   玩手机、逆行、不让行人             → 操作不规范 → 3 分
   灯光、安全带、载物、压线           → 轻微不规范 → 1 分
```

### 别混淆：记分 ≠ 罚款 ≠ 拘留/坐牢

```
   记 1 分 的行为，也可能要罚款（比如违停）
   记 12 分 的行为，一定暂扣/吊销驾照 + 可能拘留甚至坐牢

   记分   = 对"驾驶资格"的累积评价（12 分满就要回炉）
   罚款   = 经济处罚（交钱）
   拘留/吊销/入刑 = 人身自由和资格的处罚（最重的单独算）
```

> 🔑 **总口诀：要命的十二，大隐患的九，闯红灯六，分心逆行三，小毛病一分。扣分看危险，离人命越近扣越狠。**
