# 第六档 2000 ~ 5000 元 —— 号牌造假（最狠，都说故事）

> 这一档是**针对号牌、证件造假**的重罚。
> 号牌是车的"身份证"，造假就是冲着整个交通管理秩序来的，所以罚得最狠，还常常伴随**拘留**。
> 一句话：**凡是"假的、套的、变造的"，全在这一档。**

---

## ① 伪造、变造机动车号牌 —— 2000~5000 元 + 拘留

```
   大柱在电脑前："做个假牌照，超速就查不到我啦！"
         │
   🖨️  打印、喷漆、做出一副假号牌
         │
        🚗  挂上假牌开出去飙车
         │
         ↓
   ╔═══════════════════╗
   ║ 大数据一比对，露馅！║  做假牌：2000~5000元 + 拘留
   ║ 伪造号牌 = 犯罪     ║  还留案底
   ╚═══════════════════╝
```

大柱为了飙车不被查，自己上网买了套假号牌工具，喷漆做了一副"京A·88888"的假牌挂上。结果刚开出去超速被拍，交警一查——这号段根本没这辆车。**做假牌是犯罪，罚 2000~5000 元，人还被拘留，留下案底。**

> **后果**：伪造、变造机动车号牌 = **罚 2000~5000 元 + 拘留**，构成犯罪的追究刑事责任。
>
> **口诀**：假牌照别做，做了就拘留；车牌是身份证，造假就是犯罪人。

```
   马三："证丢了补办太麻烦，自己做一个呗。"
         │
   📄  网上PS了一张行驶证、登记证书
         │
        🚗  拿着假证想去过户/年检
         │
         ↓
   ╔═══════════════════╗
   ║ 窗口一验，假的！    ║  造假证：2000~5000元 + 拘留
   ║ 假证件也跑不掉     ║
   ╚═══════════════════╝
```

马三的车行驶证丢了，嫌补办麻烦，干脆自己 PS 了一张，还做了本假的登记证书，想拿着去办过户。结果窗口工作人员一扫描——证件编号对不上，假的！**造假证件和造假牌一个待遇：罚 2000~5000 元 + 拘留。**

> **后果**：伪造、变造行驶证、登记证书 = **罚 2000~5000 元 + 拘留**。
>
> **口诀**：证件丢了去补办，自己造假更麻烦；PS 一张爽一时，拘留罚款加案底。

## ③ 使用伪造、变造的号牌/证件 —— 2000~5000 元 + 拘留 + 扣车

```
   大柱："假牌都做好了，今天上路试试！"
         │
        🚗  挂着假牌、揣着假证上路
         │
   📷  被摄像头拍到，系统报警
         │
         ↓
   ╔═══════════════════╗
   ║ 用假牌上路！       ║  用假：2000~5000元 + 拘留 + 扣车
   ║ 车直接扣走         ║  三重处罚
   ╚═══════════════════╝
```

大柱做好了假牌，第二天就大摇大摆挂着上路了。刚开出去没多远，被路口摄像头拍到，系统自动报警——这号牌是假的！交警一拦，**不仅罚 2000~5000 元、拘留，连车都被直接扣走了。**

> **后果**：使用伪造、变造的号牌或证件 = **罚 2000~5000 元 + 拘留 + 扣留车辆**，三重处罚一起上。
>
> **口诀**：假牌上路必被查，摄像头前无处藏；用了假证假牌照，扣车拘留一个不少。

```
         │
   🚗  把自己的牌换成网上买的"保时捷"号牌
         │
        💨  套着别人的号上路超速
         │
         ↓
   ╔═══════════════════╗
   ║ 套牌！大数据秒破   ║  套牌：2000~5000元 + 拘留
   ║ 真车主都跟着倒霉   ║  一锅端
   ╚═══════════════════╝
```

大柱想超速不被查，花几百块买了套保时捷的号牌，把自己的车套上了。结果被交警大数据一比对——"这辆保时捷怎么同时在两个地方出现？"假套牌当场露馅。**套牌不仅大柱被罚 2000~5000 元、拘留，连被套牌的真车主都被牵连调查，一锅端。**

> **后果**：使用其他车辆的号牌、行驶证（套牌）= **罚 2000~5000 元 + 拘留 + 扣车**，还连累真车主。
>
> **口诀**：套别人的牌想躲查，大数据前一秒破；害了别人害自己，拘留罚款跑不了。
