# 第四档 500 ~ 2000 元 —— 坑人也要罚（都说故事）

> 这一档专门惩罚**自己不守法、还害别人一起违法**的行为。
> 核心就一句话：**把车交给不该开的人**、**逼别人违章**。自己犯错还连累别人，罚的就是你。

---

## ① 把车交给没证的人开 —— 500~2000 元（罚车主）

```
   马三："哥，我没证，但我会开！"
         │
   大柱："行，车给你，帮我开回去。"
         │
        🚗💨  没证的人坐上了驾驶座
         │
         ↓
   ╔═══════════════════╗
   ║ 半路被拦下         ║  无证驾驶 + 车主连带受罚
   ║ 车主：500~2000元   ║  500~2000元（罚车主！）
   ╚═══════════════════╝
```

马三喝了两口，说自己没驾照但车技好，求大柱把车借他开回去。大柱心软答应了。结果马三刚开出去两条街就被交警拦下——人没证，车是大柱的。**开车的人罚，车主大柱也跟着罚 500~2000 元。**

> **后果**：把车交给无证的人驾驶，**车主罚 500~2000 元**，开车的人另外按无证驾驶处理（可拘留）。
>
> **口诀**：车借给谁要看证，没证硬开你连坐；心软借车一时爽，罚单到手悔不该。

---

## ② 把车交给驾照被暂扣/吊销的人开 —— 500~2000 元（罚车主）

```
   王小雅的驾照：被暂扣中 ❌
         │
   王小雅："我证被扣了，但车不能没人开。"
         │
   大柱："那我帮你开。"
         │
        🚗  暂扣期间开车上路
         │
         ↓
   ╔═══════════════════╗
   ║ 被拦下，一查一个准  ║  车主：500~2000元
   ║ 严重可吊销车主驾照  ║  还可能吊销！
   ╚═══════════════════╝
```

王小雅的驾照因为闯红灯被暂扣了，可孩子放学没人接，她情急之下让大柱帮忙开。结果被交警拦下，一查驾照状态是"暂扣"。**开车的大柱罚，车主王小雅也跟着罚 500~2000 元，严重的连她的驾照都可能被吊销。**

> **后果**：把车交给驾照被暂扣、吊销的人驾驶，**车主罚 500~2000 元**，情节严重的可以吊销车主的驾照。
>
> **口诀**：证被扣了别动车，借人代开双双罚；暂扣吊销期间里，一天都不能碰方向盘。

---

## ③ 强迫、指使他人违章驾车造成事故 —— 500~2000 元 + 可拘留

```
   马三（老板）："快！闯红灯赶过去，客户等着呢！"
         │
   司机小张：不敢不从，硬着头皮闯了红灯
         │
        🚗💨  结果撞了人
         │
         ↓
   ╔═══════════════════╗
   ║ 出事故了！         ║  指使者：500~2000元 + 拘留
   ║ 幕后指使的也跑不掉  ║  造成事故罪加一等
   ╚═══════════════════╝
```

马三当老板的，出差赶时间，逼司机小张闯红灯抄近道。小张不敢违抗，硬闯了过去，结果"砰"一声撞了人。事故一查，**不光开车的小张要负责，幕后指使的马三也被揪了出来——罚 500~2000 元，还可能拘留。**

> **后果**：强迫、指使他人违章驾车造成事故的，**指使者罚 500~2000 元**，造成严重后果的还要追究刑事责任。
>
> **口诀**：逼人违章出事故，幕后指使一样罚；别拿别人的方向盘撒气，出了事谁都跑不掉。

## ④ 故意损毁、移动交通设施 —— 500~2000 元 + 可拘留

```
   大柱："这红绿灯挡我视线了，挪一下！"
         │
   🚧  大柱下车把红绿灯、护栏给掰歪了
         │
        ⚠️  路口瞬间没了信号
         │
         ↓
   ╔═══════════════════╗
   ║ 破坏公共设施！      ║  500~2000元 + 拘留
   ║ 害的是所有过路的人  ║  还可能赔钱
   ╚═══════════════════╝
```

大柱嫌路口的红绿灯挡他开车视线，下车三下五除二把信号灯掰歪、护栏也挪了位。结果这个路口一下子没了信号，几辆车抢着过差点撞一起。**破坏交通设施害的是所有人，大柱不仅罚 500~2000 元，还被拘留，损坏的东西还得赔。

> **后果**：故意损毁、移动交通设施，**罚 500~2000 元**，可并处拘留，造成损失的还要赔偿。
>
> **口诀**：红绿灯护栏是公物，动它一下害众人；为图自己一时便，拘留罚款加赔偿。

## 本档小结

```
这一档的共同点：不是自己开错，而是"害别人一起违法"

  把车给没证的人      → 车主罚 500~2000
  把车给证被扣的人    → 车主罚 500~2000（可吊销）
  逼人违章出事故      → 指使者罚 500~2000 + 拘留
  破坏交通设施        → 罚 500~2000 + 拘留 + 赔偿

记住：这一档罚的是"连累别人"和"破坏公物"，
     凡是让别人跟着你违法的，都往这档里塞。
```
