# 七、记分周期与满分处理（讲故事）

> 这一篇只讲一件事：**驾照上的 12 分是怎么扣的、什么时候清零、扣满了怎么办。**
> 把记分想成一张**信用卡额度**：每个周期给你 12 分，违章就是刷卡，刷爆了就麻烦。
> 出场：王小雅（两踏板，刚拿证）、王大山（老王，老司机）、刘建国（白手套·交警）、王大柱（大力士，B2 货车）

---

## 第一幕 · 小雅收到第一张罚单

小雅实习期第 3 个月，开车闯了个红灯，被刘建国拦下。

```
   ╭─────────╮                 ╔═════════╗
   │ ◕     ◕ │   王小雅        ║ ⊙     ⊙ ║  刘建国（白手套）
   │    ‿    │                 ║    ─    ║
   ╰────┬────╯                 ╚════┬════╝
     ／ │ ＼                    〔白手套一挥〕
   〔手机〕
```

刘建国："闯红灯，一次记 **6 分**。"

小雅脸一皱："6 分？！我驾照一共才……12 分吗？"

老王在旁边端着茶杯："对，**一个记分周期，满分 12 分。** 从你**第一次领证那天**起算，每 12 个月是一个周期。"

```
   记分周期时间轴（从领证日起算）
   领证日 ──── 3个月 ──── 6个月 ──── 9个月 ──── 领证日（满12个月）
     │                                              │
     └──────────── 这 12 个月 = 一个记分周期 ─────────┘
                                                      │
                                                      ▼
                                              下一个周期重新开始
```

> 🔑 **口诀：驾照十二分，一年一个周期；从领证那天算，不是从过年那天算。**

---

## 第二幕 · 分数是怎么扣的（分值档次）

小雅问："那违章一次扣几分？"

老王："记住几个档就行——**1、3、6、9、12**，越严重扣越多。"

```
   记分分值档次
   ┌──────────────────────────────────────────────┐
   │  12 分  ← 最狠：酒驾、逃逸、伪造号牌、超速50%以上 │
   │   9 分  ← 遮挡污损号牌、准驾不符、违停高速         │
   │   6 分  ← 闯红灯、占用应急车道、不避让校车         │
   │   3 分  ← 打电话、抽烟、不系安全带、逆行           │
   │   1 分  ← 不按规定用灯、违规载物                   │
   └──────────────────────────────────────────────┘
```

### 小雅的噩梦演示

```
   小雅这个周期的账本
   ┌─────────────────────────────────┐
   │  期初余额：12 分                  │
   │  闯红灯      -6   → 剩 6         │
   │  高速违停    -9   → 剩 -3  ❌爆仓 │
   └─────────────────────────────────┘
```

刘建国："你这周期已经**超过 12 分**了，得去处理。"

> 🔑 **口诀：一二三六九十二，违章轻重看档位；一次记满十二分，马上就得去报到。**

---

## 第三幕 · 周期到了，分数怎么算（清零规则）

转眼到年底，小雅紧张地跑去车管所问周敏。

```
   ╭─────────╮
   │ ⊙     ⊙ │   周敏（一窗通）
   │    ‿    │
   ╰────┬────╯
   〔窗 │ 口〕
```

周敏查了系统："你上个周期扣了 9 分，**没到 12 分**——恭喜，**分数自动清零**，新周期又是满血 12 分。"

```
   周期结束时的三种结局
   ┌────────────────────────────────────────────┐
   │  扣分 < 12   → 分数清零，满血复活            │
   │  扣分 = 12   → 不清零！要去参加满分学习考试  │
   │  扣分 > 12   → 同上，还要额外考科目一        │
   └────────────────────────────────────────────┘
```

> 🔑 **口诀：没到十二分，到期自动清；满了十二分，清零没你份——得去学习考试。**

---

## 第四幕 · 扣满 12 分怎么办（满分处理）★最重要

大柱（B2 大货车司机）因为超载+闯红灯，这个周期正好记满 12 分，被通知去"回炉"。

```
    ______      ┌────────────────┐
   |  __  |     │                │
   | |  | |_____│    货厢/渣土斗  │   王大柱，B2，记满 12 分
   |_|__|_|     │                │
     (o)        └────────────────┘
```

刘建国："大柱，你本周期记满 12 分了。**七日内**到机动车驾驶证核发地或者违法行为地公安机关交通管理部门，接受**为期七日的道路交通安全法律、法规和相关知识学习和考试**。"

### 满分处理流程

```
   记满 12 分
       ↓
   ① 七日内 → 到交管部门报到
       ↓
   ② 参加【七日满分学习】（学法规）
       ↓
   ③ 考【科目一】（理论）
       ↓
   ┌───────────────┴────────────────┐
   │  考过  → 分数清零，拿回驾照      │
   │  考不过 → 继续学、继续考，直到过 │
   └────────────────────────────────┘
```

### 关键数字（必背）

| 项目 | 规定 |
| --- | --- |
| 多久去报到 | 记满 12 分后 **七日内** |
| 去哪 | 驾驶证**核发地**或**违法行为地**交管部门 |
| 学什么 | **七日满分学习**（道路交通安全法律法规） |
| 考什么 | **科目一**（理论） |
| 考不过 | 继续学习考试，**直到合格** |
| 合格后 | 记分**清零**，发还驾驶证 |

> 🔑 **口诀：满十二分七日报，七天学习考科一；考过清零还你证，不过接着学到会。**

---

## 第五幕 · 一个周期两次满 12 分（更狠的情况）

大柱哭丧着脸："要是我这个周期清了零，**又**被扣满 12 分呢？"

刘建国冷笑："那就别怪我不客气——"

```
   一个记分周期内记满 12 分两次
        ↓
   ┌──────────────────────────────────────┐
   │  ① 重新参加【七日满分学习】            │
   │  ② 考【科目一】                        │
   │  ③ 还要考【科目三】（路考）！          │
   └──────────────────────────────────────┘
```

> ⚠️ **易错点**：一个周期**两次**满 12 分，除了科一，**还要重考科目三**。这是专门治"屡教不改"的。

> 🔑 **口诀：一次满分考科一，两次满分加科三；屡教不改就加码，路考也得再来遍。**

---

## 第六幕 · 拒不学习考试的后果

大柱嫌麻烦，拖着不去学习。老王摇头："你要是不去，后果更严重。"

```
   记满 12 分，逾期不参加学习考试
        ↓
   ┌──────────────────────────────────────┐
   │  公安机关公告：你的驾驶证【停止使用】   │
   │  公告期间继续开车 = 无证驾驶 / 吊销风险 │
   └──────────────────────────────────────┘
```

刘建国："公告期内你还敢上路，查到就按**无证驾驶**处理。"

> 🔑 **口诀：满分解不掉就别开，公告停用还在跑，查到就是无证驾。**

---

## 第七幕 · 老王给小雅的忠告（A/B 类更严）

小雅松了口气："还好我只扣了 6 分。"

老王："C 类（小车）相对宽松。**A、B 类大车更严**——"

```
   A/B 类大中型车 特别规定
   ┌────────────────────────────────────────────┐
   │  一个周期有记分（哪怕不到12分）              │
   │       → 周期结束后 30 日内要【审验】         │
   │  本周期【没有记分】                          │
   │       → 免予本次审验                         │
   └────────────────────────────────────────────┘
```

> 🔑 **口诀：大车有分就要审，没分免审一身轻；小车一般不用审，到期换证就行。**
