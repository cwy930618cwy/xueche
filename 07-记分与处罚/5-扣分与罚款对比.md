# 七、扣分 vs 罚款 —— 一张表彻底分清（讲故事）

> 很多人考科目一都搞混：**扣分**和**罚款**到底是两码事还是同一件事？
> 这篇用大白话 + 对比表 + 故事，把它们彻底讲清楚。**看完这篇，再也不会混。**
> 出场：王小雅（两踏板，负责犯错）、王大山（老王，正确示范）、刘建国（白手套·交警）、王大柱（大力士 B2）、马三（加塞王）

# ════════════════════════════════════════
# 〇、终极判断规则 —— 三步搞定，再也不晕
# ════════════════════════════════════════

别再背一堆数字了！**判断一个违章"扣不扣分、罚不罚款"，只看一件事：这个行为是什么性质？**

```
              遇到一个违章行为
                   │
                   ▼
        ┌──────────────────────┐
        │ 它危不危险？          │
        │ 有没有直接威胁安全？   │
        └──────────┬───────────┘
                   │
       ┌───────────┼────────────┐
       ▼           ▼            ▼
   【危险】     【一般通行】    【纯手续】
   危及生命    影响秩序但不致命   只是证件/停车没做好
       │           │            │
       ▼           ▼            ▼
   又扣又罚      也扣也罚       只罚不扣
   (分+钱)     (分少+钱少)     (只有钱)
       │           │            │
       ▼           ▼            ▼
   严重的还会
   拘留 / 吊证
```

### 三类行为，三句话记死

| 类别 | 判断标准 | 处罚 | 典型例子 |
| --- | --- | --- | --- |
| 🟢 **纯手续类** | 只是证件、标志、停车没弄好，**不涉及危险驾驶** | **只罚款，不扣分** | 忘带驾照、没贴年检标、车牌没挂好、路边违停、没系安全带 |
| 🟡 **一般通行类** | 违反了行车规则、影响秩序，**但不至于出大事** | **又扣分，又罚款**（分少钱少） | 闯红灯、压线、超速、逆行、不礼让行人、闯禁行 |
| 🔴 **危险恶性类** | **直接威胁生命安全**，或性质特别恶劣 | **重扣重罚**，还可能**拘留、吊证** | 酒驾、醉驾、肇事逃逸、无证驾驶、严重超载、伪造号牌 |

> 🔑 **一句话规则：只要"动了手、要了命、造了假"就是🔴重罚；只是"乱了秩序"就是🟡又扣又罚；只是"手续没办全"就是🟢只罚钱。**

### 用一个故事串起来：马三的一天

同样是马三，一天之内犯了三种不同性质的错——你就看清区别了：

```
   🟢 纯手续                🟡 一般通行               🔴 危险恶性
   ┌──────────┐           ┌──────────┐            ┌──────────┐
   │ 忘带驾照   │           │ 闯了个红灯  │            │ 喝醉了开车  │
   │ 只罚200   │    →      │ 扣6分罚200 │     →      │ 扣12分+吊证 │
   │ 不扣分    │           │ 又扣又罚    │            │ +拘留+追刑责 │
   └──────────┘           └──────────┘            └──────────┘
      手续没带齐              扰乱了秩序               要命了！
```

**① 早上忘带驾照（🟢 纯手续）**
马三出门急没带驾照，被拦下。
刘建国："未携带驾驶证，**罚款 20~200 元，不扣分**。" → *因为没带证不等于你开车危险，只是手续没全。*

**② 中午闯红灯（🟡 一般通行）**
马三赶时间闯了红灯。
刘建国："闯红灯，**记 6 分 + 罚款 200 元**。" → *因为你破坏了行车秩序，有危险，所以要扣分也要罚钱。*

**③ 晚上喝酒开（🔴 危险恶性）**
马三饭局喝多了还上路。
刘建国："醉酒驾驶！**记 12 分 + 罚款 1000~2000 元 + 吊销驾照 + 追究刑事责任**！" → *因为你随时会撞死人，性质最恶劣，所以往死里罚。*

> 🔑 **看懂了吗？同一个马三，行为越危险，处罚越狠。判断的关键永远是——这件事有多危险。**

## 一句话先记住

> 🔑 **扣分是"记你一笔账"，罚款是"掏钱给你开罚单"。一个是分数，一个是钱。**

```
   扣分                          罚款
   ┌──────────┐                 ┌──────────┐
   │    12    │  ← 分数         │   ¥      │  ← 钱
   │  驾照上   │                 │  钱包里   │
   │  的额度   │                 │  往外掏   │
   └──────────┘                 └──────────┘
      虚拟的                       真金白银
   （攒满12分有后果）           （当场就要交）
```

# ════════════════════════════════════════
# 第一块　核心区别 —— 一张表看懂
# ════════════════════════════════════════

| 对比项 | 扣分（记分） | 罚款 |
| --- | --- | --- |
| **扣的是什么** | 驾照上的**分数**（虚拟） | 口袋里的**钱**（真金白银） |
| **满分多少** | 一个周期 **12 分** | 没有上限，按档位算 |
| **怎么算周期** | 领证日起 **12 个月**一个周期，期满清零 | 没有周期，违章一次罚一次 |
| **谁来执行** | 公安机关交通管理部门记录在案 | 财政部门收缴，进国库 |
| **满了怎么办** | 扣满 12 分 → 回炉重考科目一 | 不交 → 每天加收 3% 滞纳金 |
| **会不会留痕** | 会，记在驾照档案里 | 会，记在违法记录里 |
| **能不能抵消** | 不能，分就是分了 | 交了就没后续 |

> 🔑 **口诀：扣分记在驾照上，满十二分要回炉；罚款掏的是真钱，不交天天涨滞纳。**

# 第二块　它们的关系 —— 常常一起出现
# ════════════════════════════════════════

**关键认知：扣分和罚款不是二选一，而是经常"双管齐下"——同一个违章，既扣分又罚款。**

```
        一个违章行为
             │
     ┌───────┴────────┐
     ▼                ▼
  扣几分？          罚多少钱？
 （看严重程度）     （看金额档位）
     │                │
     └───────┬────────┘
             ▼
      两个都要承担！
```

### 场景：马三闯红灯，又扣分又罚钱

马三开车闯了个红灯，被刘建国拦下。

```
   ┌────────────────────────┐
   │  马三  (o)  😰           │
   │   🚗  💥                │
   │   红灯直接冲过去了        │
   └────────────────────────┘
```

刘建国："闯红灯，**记 6 分**，**罚款 200 元**。"

```
   ┌────────────────────────────────────────────┐
   │  闯红灯                                      │
   │       ↓                                      │
   │  ① 记分：一次记 6 分（驾照上少了 6 分）         │
   │  ② 罚款：200 元（当场开罚单交钱）               │
   └────────────────────────────────────────────┘
```

马三懵了："等等——我既要扣分，又要交钱？**同一件事罚两次？**"

老王在旁边笑："不是罚两次，是**一件事有两个代价**——你的驾照上要记 6 分，你的钱包里要少 200 块。**这俩是配套的，不是二选一。**"

> 🔑 **口诀：一个违章两份账，既扣分数又扣钱；记分罚款手牵手，同时上门别抱怨。**

## 易混点 1：是不是每个违章都扣分？

**不是！** 有些违章只罚款，不扣分。

| 情形 | 扣分 | 罚款 |
| --- | --- | --- |
| 闯红灯 | ✅ 记 6 分 | ✅ 罚 200 元 |
| 违停（路边停车） | ❌ 不扣分 | ✅ 罚 20 ~ 200 元 |
| 没系安全带 | ❌ 一般不记分 | ✅ 罚 20 ~ 200 元 |
| 酒驾 | ✅ 记 12 分 | ✅ 罚 1000~2000 元 |

> 🔑 **记忆：涉及危险驾驶行为（闯红灯、酒驾、逆行）通常既扣分又罚款；纯手续性小毛病（违停、没带证）往往只罚款不扣分。**

## 易混点 2：扣满 12 分会不会直接吊销驾照？

**不会！** 扣满 12 分 ≠ 吊销驾照，这是最容易错的。

```
   扣满 12 分的后果                    吊销驾照的情形
   ┌──────────────────┐              ┌──────────────────┐
   │ ① 扣留驾驶证       │              │ • 醉驾            │
   │ ② 重考科目一       │   ≠          │ • 肇事逃逸构成犯罪  │
   │ ③ 考过才能上路     │              │ • 重大事故负主责    │
   │                    │              │                   │
   │  驾照还在！         │              │  驾照作废！         │
   │  只是暂时不能用     │              │  终生/限期不能再考   │
   └──────────────────┘              └──────────────────┘
```

### 场景：马三以为扣满 12 分就完了

马三一个周期内东闯西超，累积扣到了 12 分，吓得大哭："我驾照是不是没了？要被吊销了？"

```
   ╭─────────╮
   │ ◕     ◕ │  马三 哭唧唧
   │    ‿    │  "12分了！我驾照废了！"
   ╰────┬────╯
     ／ │ ＼
   〔泪崩〕
```

刘建国扶额："你先别慌。**扣满 12 分，是扣留你的驾驶证，让你回去重考科目一**——考过了，分数清零，驾照还给你。"

```
   ┌────────────────────────────────────────────┐
   │  一个记分周期内累积记满 12 分                  │
   │       ↓                                      │
   │  ① 公安机关扣留机动车驾驶证                     │
   │  ② 参加为期 7 天的道路交通安全法律学习           │
   │  ③ 考科目一（考试合格）                         │
   │  ④ 记分清零，发还驾驶证                         │
   └────────────────────────────────────────────┘
```

老王补充："只有**拒不接受处理、拒不参加学习考试**，或者**在一个周期内两次记满 12 分**，才会加重处理。**正常的 12 分，就是'回炉重造'，驾照不会吊。**"

> 🔑 **口诀：十二分满别吓哭，回炉重考科目一；考过清零证还你，吊证那是另一回事。**

## 易混点 3：罚款不交会怎样？扣分会有滞纳金吗？

**罚款不交，每天加收 3% 滞纳金；扣分本身没有滞纳金，但会影响你处理业务。**

```
   罚款逾期不交
   本金 200 元
      │
      ▼ 每天 +3%
   第 1 天  206 元
   第 2 天  212 元
   第 3 天  218 元  ……越滚越多
      │
      ▼ 最高不超过本金的 2 倍
   封顶 400 元
```

> 🔑 **记忆：滞纳金只对"罚款"生效，按日加收 3%，最高不超过罚款本金的 2 倍。扣分不涉及滞纳金。**

# 第四块　完整对照 —— 常见违章扣几分罚多少
# ════════════════════════════════════════

把常考的违章列在一起，**左边看扣几分，右边看罚多少**，一目了然。

| 违法行为 | 记分 | 罚款 | 其他处罚 |
| --- | --- | --- | --- |
| 醉酒驾驶 | **12 分** | 1000 ~ 2000 元 | 吊证 5 年、追刑责 |
| 饮酒驾驶 | **12 分** | 1000 ~ 2000 元 | 暂扣驾照 6 个月、可拘留 |
| 造成交通事故后逃逸（不构成犯罪） | **12 分** | 200 ~ 2000 元 | 可拘留 15 日以下 |
| 闯红灯 | **6 分** | 200 元 | — |
| 占用应急车道 | **6 分** | 200 元 | — |
| 不避让校车 | **6 分** | 200 元 | — |
| 逆行 | **3 分** | 200 元 | — |
| 超速 20%~50% | **3 分** | 200 元 | — |
| 人行横道不停车让行 | **3 分** | 200 元 | — |
| 无证驾驶 | **—**（不记分） | 200 ~ 2000 元 | 可拘留 15 日以下 |
| 把车交给无证的人开 | **—** | 500 ~ 2000 元 | 可吊证 |
| 未随车携带驾驶证 | **—** | 20 ~ 200 元 | — |
| 违规停车 | **—** | 20 ~ 200 元 | — |
| 未系安全带 | **—** | 20 ~ 200 元 | — |
| 伪造、变造号牌 | **—** | 2000 ~ 5000 元 | 拘 15 日以下 |

> 🔑 **规律总结**：
> - **危险驾驶类**（酒驾、逃逸、闯红灯、逆行）→ **既扣分又罚款**
> - **手续缺失类**（没带证、违停、没系安全带）→ **只罚款，不扣分**
> - **资格造假类**（伪造号牌、把车给无证者）→ **重罚款 + 可能拘留，不一定记分**

# 第五块　一句话总纲
# ════════════════════════════════════════

```
   ┌─────────────────────────────────────────────┐
   │                                               │
   │   扣分 = 驾照上的分数，攒满 12 分回炉重考        │
   │   罚款 = 钱包里的真钱，不交每天涨 3%            │
   │                                               │
   │   两者常常一起出现：                           │
   │   一个违章，既扣你的分，也扣你的钱               │

   │   危险驾驶 → 又扣又罚                          │

   │   资格造假 → 重罚 + 拘留                       │
   │                                               │
   └─────────────────────────────────────────────┘
```

> 🔑 **终极口诀：扣分记驾照，罚款掏钱包；二者常相伴，一个都跑不掉。危险驾驶双管下，手续小错只罚钱；十二分满别害怕，回炉重考证还在。**
