# 七、罚款金额全解（讲故事）

> 上一篇《罚款与处罚措施》把拘留、吊销、扣留都揉在一起了，罚款只匆匆带过几档。
> 这篇**专门把罚款讲透**——科目一要考的罚款档位，一共 **六档**，从最低 20 元到最高 5000 元，一档不漏，档档配故事。
> 记住一句话：**违法越重，口袋掏得越多。**
> 出场：王小雅（两踏板，负责犯错）、王大山（老王，正确示范）、刘建国（白手套·交警）、王大柱（大力士 B2）、王小龙（两轮小飞 E）、马三（加塞王）、张大嘴（劝酒张）

---

## 先看全貌：罚款六档

```
   罚款金额阶梯（从低到高）
   ┌────────────────────────┐
   │     2000 ~ 5000 元      │  ← 最狠：假牌、套牌
   ├────────────────────────┤
   │     1000 ~ 2000 元      │  ← 醉驾
   ├────────────────────────┤
   │      500 ~ 2000 元      │  ← 把车给无证的人开、强迫他人违章
   ├────────────────────────┤
   │      200 ~ 2000 元      │  ← 无证、酒驾、逃逸、超载
   ├────────────────────────┤
   │      200 ~ 500 元       │  ← 一般通行违法
   ├────────────────────────┤
   │       20 ~ 200 元       │  ← 一般程序小毛病
   └────────────────────────┘
```

| 档位 | 关键词 | 典型行为 |
| --- | --- | --- |
| **20 ~ 200 元** | 小毛病 | 忘带证、没挂牌、没系安全带、违停 |
| **200 ~ 500 元** | 一般通行违法 | 闯禁行、超速、压线、不按规定让行 |
| **200 ~ 2000 元** | 较重 | 无证驾驶、饮酒驾驶、逃逸未构成犯罪、超载 |
| **500 ~ 2000 元** | 坑人 | 把车交给没证的人开、强迫/指使他人违章驾车 |
| **1000 ~ 2000 元** | 醉驾 | 醉酒驾驶机动车 |
| **2000 ~ 5000 元** | 号牌造假 | 伪造变造号牌、使用其他车辆号牌（套牌） |

> 🔑 **总口诀：二十两百小毛病，两百五百普通行；两千以内无证酒，五千以内假牌坑；醉驾一千到两千，号牌造假两千起。**

# 第二档　200 ~ 500 元 —— 一般通行违法
# ════════════════════════════════════════

> 这一档是**违反了道路通行的具体规定**，已经影响到行车秩序了，比"忘带证"重一级。

### 本档常见情形

| 行为 | 说明 |
| --- | --- |
| 违反禁令标志、禁止标线 | 压单行线、闯禁行区 |
| 不按规定车道行驶 | 直行道转弯、占用专用道 |
| 违反交通信号灯通行 | 闯红灯（部分情形） |
| 不按规定超车、让行 | 乱加塞、抢行 |
| 超速行驶 | 超过限速但未到 50% |
| 货车闯禁行 | 禁止货车路段硬闯 |

### 场景：大柱为了赶时间，连闯两个禁行

# ════════════════════════════════════════

> 这一档是**性质比较严重的违法**，往往伴随着危险，金额跨度也大。科目一最爱考的就是这一档。

### 本档常见情形

| 行为 | 说明 |
| --- | --- |

| 超速 50% 以上 | 严重超速 |
| 驾驶拼装的机动车 | 开报废拼装车 |

### 场景：马三的"三连作死"之夜

```
   ┌────────────────────────────────────────────┐

   │       ↓                                      │

   │  + 记分：酒驾记 12 分、逃逸记 12 分              │
```

# ════════════════════════════════════════
# 第五档　1000 ~ 2000 元 —— 醉酒驾驶
# ════════════════════════════════════════════

> 这一档**单独一档**，因为醉驾入刑，是科目一的绝对重点。注意：饮酒驾驶和醉酒驾驶不是一回事，血液酒精含量 ≥ 80mg/100ml 才算醉驾。

### 区分：酒驾 vs 醉驾

| 类型 | 血液酒精含量 | 性质 | 罚款 |
| --- | --- | --- | --- |
| **饮酒驾驶** | 20 ~ 80 mg/100ml | 违法 | 1000 ~ 2000 元 + 记 12 分 + 暂扣 6 个月 |
| **醉酒驾驶** | ≥ 80 mg/100ml | **犯罪** | 1000 ~ 2000 元 + 吊证 + 追刑责 |

### 场景：张大嘴劝酒，马三真醉了还开

还是那个老饭局——张大嘴死活劝，马三喝到走路打晃，还坚持"我没醉，能开"。

```
   ╭─────────╮              ┌──────────┐
   │  ▔▔▔    │  马三         │  🍺🍺    │
   │ ⊙     ⊙ │  走路打晃      │  打嗝…   │
   ╰────┬────╯              └──────────┘
     ／ │ ＼
   〔方向盘画龙〕
```

# 第六档　2000 ~ 5000 元 —— 号牌造假（最狠）
# ════════════════════════════════════════════

> 这一档是**针对号牌、证件造假**的重罚。号牌是车的"身份证"，造假就是冲着整个交通管理秩序来的，所以罚得最狠，还常常伴随拘留。

### 本档常见情形

| 行为 | 说明 |
| --- | --- |
| 伪造、变造机动车号牌 | 做假牌照 |
| 伪造、变造行驶证、登记证书 | 造假证件 |
| 使用伪造、变造的号牌/证件 | 用假牌上路 |
| 使用其他车辆的号牌、行驶证 | 套牌 |
| 伪造、变造检验合格标志、保险标志 | 造假标贴 |

### 场景：大柱的"省钱"假牌，代价五千块

大柱为了省那点牌照费和相关税费，找人**做了一个假牌照**，还套用了别人的号牌——结果电子眼识别异常，车被扣了。

```
   ┌────────────────────────┐
   │  🚛 大柱                 │
   │   京A·XXXXX ← 假牌       │
   │   套别人的号             │
   │      车证都被收走         │
   └────────────────────────┘
```

刘建国："**伪造、变造或使用伪造变造的号牌、行驶证**，或者**套用其他车辆号牌**的，**收缴、扣留机动车**，处 **15 日以下拘留**，并处 **2000 元以上 5000 元以下罚款**；构成犯罪的，追究刑事责任！——注意，**这个不记分，直接拘留+罚款，比重扣分狠多了。**"

```
   ┌────────────────────────────────────────────┐
   │  伪造/变造/使用伪造变造的号牌、行驶证、套牌等     │
   │       ↓                                      │
   │  收缴 + 扣留机动车                             │
   │  + 15 日以下拘留（不记分）                       │
   │  + 罚款 2000 ~ 5000 元                        │
   │  + 构成犯罪的，追究刑事责任                      │
   └────────────────────────────────────────────┘
```

大柱瘫软："就一个假牌，至于罚这么多？"

老王："号牌是车的**身份证**。你造假身份、套别人身份上路，性质比无证还恶劣——**今天顶格罚你 5000，还算轻的。这套牌一旦牵出别的案子，就不是罚款能了结的了。**"

> 🔑 **口诀：假牌套牌别去碰，两千到五千是起步；不记分来直接拘，刑事追责才算真功夫。**

# 六档总览 · 速查表（考前扫一遍）
# ════════════════════════════════════════

| 档位 | 关键词 | 典型行为 | 记几分 | 记忆抓手 |
| --- | --- | --- | --- | --- |
| **20 ~ 200 元** | 小毛病 | 忘带证、没挂牌、没贴标、违停 | **不记分** | 手续没带齐 |
| **20 ~ 200 元** | 安全带 | 未按规定使用安全带 | **记 1 分** | 例外！要扣分 |
| **200 ~ 500 元** | 一般通行 | 闯禁行、压线、超速、不按车道 | **记 1 分** | 影响了秩序 |
| **200 ~ 2000 元** | 较重 | 无证、酒驾、逃逸、超载、拼装车 | 酒驾/逃逸**记 12 分**，无证不记 | 危险又恶劣 |
| **500 ~ 2000 元** | 坑人 | 把车给无证的人、强迫他人违章 | **不记分**（罚车主） | 害人一起违法 |
| **1000 ~ 2000 元** | 醉驾 | 醉酒驾驶（≥80mg/100ml，入刑） | **记 12 分** | 喝醉了还开 |
| **2000 ~ 5000 元** | 号牌造假 | 伪造变造号牌、套牌、造假证件 | **不记分**（直接拘留） | 动号牌心思 |

> 🔑 **总口诀：二十两百手续缺，两百五百秩序裂；两千以下无证酒，五千以下假牌设；醉驾千元起跳档，号牌造假最贵客。**

> 📌 **考试提醒**：题目问"罚款多少"时，先看行为属于哪一类——**程序小错选 20~200，一般通行选 200~500，无证/酒驾/逃逸选 200~2000，把车给人选 500~2000，醉驾锁定 1000~2000，号牌造假锁定 2000~5000。**

> ⚠️ **扣分规律一句话**：**安全带记 1 分，闯禁行压线记 1 分，酒驾/逃逸/醉驾一次记满 12 分**；而**忘带证、没贴标、违停、把车给无证人、伪造号牌——这些只罚钱不记分**。
