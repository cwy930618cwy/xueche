# 七、罚款与处罚措施（讲故事）

> 上一篇讲了"违章扣几分"，这篇讲**除了扣分，还要罚多少钱、关几天、吊不吊证、扣不扣车**。
> 记住一句话：**扣分是记你一笔账，罚款是真金白银往外掏；严重的还要人身自由。**
> 出场：王小雅（两踏板，负责犯错）、王大山（老王，正确示范）、刘建国（白手套·交警）、王大柱（大力士 B2）、王小龙（两轮小飞 E）、马三（加塞王）、张大嘴（劝酒张）

---

## 先看全貌：四种处罚，各管一摊

```
   处罚四件套
   ┌──────────┐
   │   罚款    │  ← 掏钱（最常见）
   ├──────────┤
   │   拘留    │  ← 限制人身自由（关几天）
   ├──────────┤
   │   吊销    │  ← 驾照直接作废
   ├──────────┤
   │  扣留     │  ← 暂时扣车 / 扣证
   └──────────┘
```

本文分成**四个独立的篇章**，一类处罚一篇，互不混杂：

| 篇章 | 讲什么 | 关键词 |
| --- | --- | --- |
| 【第一篇】 | 罚款——钱分几档 | 20~200 / 200~500 / 200~2000 / 1000~2000 / 2000~5000 |
| 【第二篇】 | 拘留——关几天 | ≤10 日 / ≤15 日 |
| 【第三篇】 | 吊销——资格作废 | 终生禁驾 / 3 年禁报 |
| 【第四篇】 | 扣留——先收着 | 扣车 / 扣证 |

> 🔑 **总口诀：罚款掏钱最寻常，拘留关人限自由；吊销证件资格没，扣留只是先收着。**

# ════════════════════════════════════════
# 第一篇　罚款 —— 钱分几档
# ════════════════════════════════════════

> 罚款是最常见的处罚。违法轻重不同，口袋里的钱掏得也不一样。下面按**金额从小到大**排。

### 本篇场景一览

| 场景 | 主角 | 行为 | 罚款 |
| --- | --- | --- | --- |
| 场景 1 | 马三 | 忘带证、没挂牌 | 20 ~ 200 元 |
| 场景 2 | 大柱 | 货车闯禁行 | 200 ~ 500 元 |
| 场景 3 | 大柱 | 货车严重超载 | 200 ~ 2000 元 |
| 场景 4 | 马三 | 醉酒驾驶 | 1000 ~ 2000 元 + 吊证 |

---

### 场景 1：马三违停买水，小错二十到两百

马三路边停车买瓶水，没带驾驶证、也没牌照——可这只是**一般的小毛病**。

```
   ┌────────────────────────┐
   │  马三  (o)               │
   │   🚗  路边一停           │
   │      "就买瓶水……"        │
   └────────────────────────┘
```

刘建国走过去："没带证、没挂牌，这些**一般程序性的小违法**，罚款 **20 元以上 200 元以下**。"

```
   ┌────────────────────────────────────────────┐
   │  未随车携带驾驶证 / 行驶证、未悬挂号牌等       │
   │       ↓                                      │
   │  罚款 20 ~ 200 元                             │
   └────────────────────────────────────────────┘
```

> 🔑 **口诀：忘带证件没挂牌，一般小错两百内。**

### 场景 2：大柱货车闯了禁行，中等过错两百到五百

大柱拉货走了一条**禁止货车通行**的路，被刘建国拦下。

```
   ┌────────────────────────┐
   │     🚛 大柱货车          │
   │        ╳                │
   │   [禁止货车驶入]         │
   └────────────────────────┘
```

刘建国："货车闯禁行，这是**一般的通行违法**，罚款 **200 元以上 500 元以下**。"

```
   ┌────────────────────────────────────────────┐
   │  违反道路通行规定（如货车闯禁行、超速等）       │
   │       ↓                                      │
   │  罚款 200 ~ 500 元                            │
   └────────────────────────────────────────────┘
```

> 🔑 **口诀：闯个禁行超点速，两三百来五百落。**

### 场景 3：大柱的货车严重超载，罚到肉疼

大柱为了多赚钱，一车拉了平时两倍多的货，被刘建国拦下过磅——**严重超载**。

```
   ┌────────────────────────┐
   │  🚛 大柱                 │
   │  ████████████ 堆成山     │
   │   超载 200%              │
   └────────────────────────┘
```

刘建国："货运机动车载物**超过核定载质量**，罚款 **200 元以上 2000 元以下**；情节严重的，还要**扣留车辆**。"

```
   ┌────────────────────────────────────────────┐
   │  货运机动车载物超过核定载质量                  │
   │       ↓                                      │
   │  罚款 200 ~ 2000 元                           │
   │  + 情节严重的，扣留机动车                       │
   └────────────────────────────────────────────┘
```

大柱擦汗："就这一趟……"

老王："你这一车压下去，桥可能塌、路可能裂，**别人不敢超的量你超了，就得承担别人几倍的罚。**"

> 🔑 **口诀：货车超载超得狠，两千罚款等着滚；情节严重车先扣。**

### 场景 4：马三醉驾被抓，重罪两千顶格还要吊证

还是那个饭局——张大嘴劝酒，马三喝多了还开车上路，吹气一测**达到醉驾标准**。

```
   ╭─────────╮              ┌──────────┐
   │  ▔▔▔    │  马三         │  🍺      │
   │ ⊙     ⊙ │              │  打嗝…   │
   ╰────┬────╯              └──────────┘
     ／ │ ＼
   〔方向盘歪了〕
```

刘建国："**醉酒驾驶**，这是犯罪！罚款 **1000 元以上 2000 元以下**，**吊销驾驶证**，五年内不得重新取得，还要追究刑事责任！"

```
   ┌────────────────────────────────────────────┐
   │  醉酒驾驶机动车                               │
   │       ↓                                      │
   │  罚款 1000 ~ 2000 元                          │
   │  + 吊销驾驶证，5 年内不得重考                   │
   │  + 依法追究刑事责任                           │
   └────────────────────────────────────────────┘
```

> 🔑 **口诀：喝酒开车不是错，是犯罪；两千罚款证吊销，五年之内别想碰。**

> 📌 **第一篇小结**：罚款从 20 元到 2000 元，越重的违法掏得越多。醉驾不仅罚得多，还直接吊证——已经跨到下一篇"吊销"的地界了。

# 第二篇　拘留 —— 限制人身自由
# ════════════════════════════════════════

> 拘留就是把人**关在看守所里，限制人身自由**。比罚款狠得多——钱没了还能再挣，自由受限可不是闹着玩的。

### 本篇场景一览

| 场景 | 主角 | 行为 | 拘留 |
| --- | --- | --- | --- |
| 场景 1 | 马三 | 饮酒后驾驶 | ≤ 10 日 |
| 场景 2 | 马三 | 未取得驾驶证驾驶（无证） | ≤ 15 日 |

---

### 场景 1：马三酒驾被拘，十日以下跑不掉

马三喝了酒开车（这回是被老王拦下的），吹气显示**饮酒驾驶**。

```
   ┌────────────────────────┐
   │  马三  (o)  🍺           │
   │   🚗  脸红扑扑           │
   │   "就两杯……"             │
   └────────────────────────┘
```

刘建国："饮酒后驾驶机动车，除了记 12 分、暂扣驾照六个月、罚款，**还可以处 10 日以下拘留**！"

```
   ┌────────────────────────────────────────────┐
   │  饮酒后驾驶机动车                             │
   │       ↓                                      │
   │  记 12 分 + 暂扣驾照 6 个月                    │
   │  + 罚款 1000 ~ 2000 元                        │
   │  + 可以并处 10 日以下拘留                       │
   └────────────────────────────────────────────┘
```

> 🔑 **口诀：喝酒开车十二分，还能拘留十天整；贪那两杯酒，换来半个月。**

### 场景 2：马三无证上路，最高可拘十五天

马三一直没能考上驾照，这天急着接孩子，偷偷把车开上了路——结果被刘建国拦下。

```
   ┌────────────────────────┐
   │  马三  (o)  😰           │
   │   🚗                     │
   │   "我就接个孩子……"       │
   └────────────────────────┘
        驾驶证？没有。
```

刘建国："你**根本没有驾驶证**，还敢上路？这属于**无证驾驶**，罚款 **200 元以上 2000 元以下**，还可以**并处 15 日以下拘留**！"

```
   ┌────────────────────────────────────────────┐
   │  未取得机动车驾驶证驾驶机动车                   │
   │       ↓                                      │
   │  罚款 200 ~ 2000 元                           │
   │  + 可以并处 15 日以下拘留                       │
   └────────────────────────────────────────────┘
```

马三慌了："拘留？真的会坐牢吗？"

老王："拘留就是**把你关在看守所里，限制人身自由**。无证驾驶抓到了，十五天是顶格的。**驾照还没考出来，老老实实等。**"

> 🔑 **口诀：没证开车叫无证，两千罚款加拘留；最多关你十五天，考完驾照再上路。**

> 📌 **第二篇小结**：酒驾关最多 10 天，无证关最多 15 天。记住——**能拘留的情形，都是性质比较恶劣的**。

# ════════════════════════════════════════
# 第三篇　吊销 —— 驾照直接作废
# ════════════════════════════════════════

> 吊销是最严厉的资格罚——**驾照直接被注销，等于你这辈子（或若干年内）别再想合法开车**。

### 本篇场景一览

| 场景 | 主角 | 行为 | 后果 |
| --- | --- | --- | --- |
| 场景 1 | 马三 | 造成交通事故后逃逸 | 终生不得重新取得 |
| 场景 2 | 马三 | 考试作弊 / 欺骗贿赂取证 | 3 年内不得再次申领 |

---

### 场景 1：马三肇事逃逸，终身禁驾

马三开车撞了路边的电动车，他一看没人注意，**一脚油门跑了**。结果电动车主重伤。

```
   ┌────────────────────────┐
   │  马三  (o)  😱           │
   │   🚗  💨  逃跑           │
   │      身后一片狼藉         │
   └────────────────────────┘
```

刘建国："**造成交通事故后逃逸**，尚不构成犯罪的，罚款 **200 元以上 2000 元以下**，**可以并处 15 日以下拘留**；**构成犯罪的**，依法追究刑事责任，并且——**由公安机关交通管理部门吊销机动车驾驶证，终生不得重新取得！**"

```
   ┌────────────────────────────────────────────┐
   │  造成交通事故后逃逸                           │
   │       ↓                                      │
   │  罚款 200 ~ 2000 元 + 可拘留 15 日以下          │
   │  + 构成犯罪的，追究刑事责任                     │
   │  + 吊销驾驶证，终生不得重新取得                  │
   └────────────────────────────────────────────┘
```

老王叹气："撞了人你不救，跑了？**这一跑，你这辈子就别想再摸方向盘了。**逃逸无上限，代价是一辈子。"

> 🔑 **口诀：撞了人别跑，跑了证就吊；终生不能再开车，逃逸代价最惨烈。**

### 场景 2：马三重考期间作弊，成绩作废证也吊

马三科目一没过，找了个"枪手"替考——被当场抓住。

```
   ┌────────────────────────┐
   │  考场                    │
   │  马三  (o)  ← 背后有人递答案│
   │        ✂️  被抓现行       │
   └────────────────────────┘
```

刘建国："**在考试过程中有欺骗、贿赂等舞弊行为的**，**取消考试资格**，已经通过的其他科目成绩**无效**；**以欺骗、贿赂等不正当手段取得驾驶证的**，收缴驾驶证，撤销许可，**申请人在三年内不得再次申领**！"

```
   ┌────────────────────────────────────────────┐
   │  以欺骗、贿赂等不正当手段取得驾驶证              │
   │       ↓                                      │
   │  收缴驾驶证 + 撤销机动车驾驶许可                 │
   │  + 申请人 3 年内不得再次申领                     │
   └────────────────────────────────────────────┘
```

> 🔑 **口诀：考试作弊耍花招，成绩作废证也吊；三年之内别想报，走正道才是真招。**

> 📌 **第三篇小结**：吊销分两种——**逃逸构成犯罪，终生禁驾**；**作弊取证，3 年禁报**。一个是"一辈子"，一个是"一阵子"。

# 第四篇　扣留 —— 暂时收着
# ════════════════════════════════════════

> 扣留不是最终处罚，只是**先把车 / 证收起来**，等你补齐手续或接受处理后再说。

### 本篇场景一览

| 场景 | 主角 | 行为 | 后果 |
| --- | --- | --- | --- |
| 场景 1 | 大柱 | 未按规定投保交强险 | 扣留机动车 + 保费 2 倍罚款 |
| 场景 2 | 大柱 | 伪造、变造号牌 / 行驶证 | 收缴 + 扣留 + 拘留 + 罚款 |

---

### 场景 1：大柱的车没保险上路，车先被扣

大柱新买的车，还没来得及上保险，就开上路了——被刘建国拦下。

```
   ┌────────────────────────┐
   │  🚛 大柱                 │
   │     "保险……还没办"       │
   │      车被开走            │
   └────────────────────────┘
```

刘建国："机动车**未按照规定投保机动车交通事故责任强制保险（交强险）**的，**扣留机动车**，并处依照规定投保最低责任限额应缴纳的保险费的 **2 倍罚款**；补办保险后，退还车辆。"

```
   ┌────────────────────────────────────────────┐
   │  未按规定投保交强险                           │
   │       ↓                                      │
   │  扣留机动车                                   │
   │  + 处保费 2 倍的罚款                           │
   │  + 补办保险后，退还车辆                         │
   └────────────────────────────────────────────┘
```

大柱哭丧脸："我的车啊……"

老王："上路就得有保险，这是**底线**。没保险你撞了人，赔不起还得法律兜底。**先把保险买好，再上路。**"

> 🔑 **口诀：上路没保险，扣车没商量；保费两倍罚给你，补上保险才放场。**

### 场景 2：大柱伪造号牌，车证全扣

大柱为了省那点牌照费，找人**做了一个假牌照**装在自己车上——结果电子眼识别异常，车被扣了。

```
   ┌────────────────────────┐
   │  🚛 大柱                 │
   │   京A·XXXXX ← 假牌       │
   │      车证都被收走         │
   └────────────────────────┘
```

刘建国："**伪造、变造或者使用伪造、变造的机动车登记证书、号牌、行驶证、检验合格标志、保险标志**的，**收缴该机动车**，**扣留该机动车**，处**十五日以下拘留**，并处 **2000 元以上 5000 元以下罚款**；构成犯罪的，依法追究刑事责任！"

```
   ┌────────────────────────────────────────────┐
   │  伪造、变造或使用伪造、变造的号牌/行驶证等        │
   │       ↓                                      │
   │  收缴 + 扣留机动车                             │
   │  + 15 日以下拘留                              │
   │  + 罚款 2000 ~ 5000 元                        │
   │  + 构成犯罪的，追究刑事责任                      │
   └────────────────────────────────────────────┘
```

大柱瘫软："就一个假牌……"

老王："号牌是车的**身份证**。你造假身份上路，性质比无证还恶劣——**套牌、假牌，都是冲着整个管理秩序来的，严惩不贷。**"

> 🔑 **口诀：假牌假证别去碰，扣车拘留加罚款；五千以下两万算轻的，刑事追责才算真功夫。**

> 📌 **第四篇小结**：扣留是"先收着"——**没保险，补上就还你**；**造假牌，那就麻烦了**，不光扣车还要拘留罚款。

# 速查表（考前扫一遍）
# ════════════════════════════════════════

### 罚款档位

| 罚款区间 | 典型情形 |
| --- | --- |
| **20 ~ 200 元** | 未随车携带驾驶证/行驶证、未悬挂号牌、未系安全带等一般程序违法 |
| **200 ~ 500 元** | 违反道路通行规定（货车闯禁行、超速等） |
| **200 ~ 2000 元** | 无证驾驶、饮酒驾驶、肇事逃逸（不构成犯罪）、严重超载 |
| **1000 ~ 2000 元** | 醉酒驾驶 |
| **2000 ~ 5000 元** | 伪造、变造号牌/行驶证 |

### 拘留 / 吊销 / 扣留

| 处罚类型 | 典型情形 | 关键数字 |
| --- | --- | --- |
| **拘留 ≤ 10 日** | 饮酒后驾驶机动车 | 酒驾 |
| **拘留 ≤ 15 日** | 无证驾驶、肇事逃逸（不构成犯罪）、伪造变造号牌 | 更重 |
| **吊销驾驶证** | 醉驾、肇事逃逸构成犯罪、重大事故负主要责任 | 资格作废 |
| **终生不得重取** | 造成交通事故后逃逸构成犯罪 | 终生禁驾 |
| **3 年内不得申领** | 以欺骗、贿赂等不正当手段取得驾驶证 | 考试作弊 |
| **扣留机动车** | 未投保交强险、伪造变造号牌、严重超载等 | 先收着 |

> 🔑 **总口诀：二十两百小毛病，两百五百通行错；两千以内无证酒，两千以上醉驾逃；拘留十天到十五，吊销三年到终身；扣车只为先收着，补齐手续再放行。**
