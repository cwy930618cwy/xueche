## 写法规范（关键，务必遵守）
每节统一用 **人物 + 画图 + 说故事 + 使用场景** 四件套：
1. 人物化：给代号/概念配 姓名+外号
2. 画图：字符画 + 关系图（文字版+Mermaid），箭头注方向
3. 说故事：知识点编进连贯故事，一幕讲一个点，幕末标「记忆点」；**每个故事/每一幕底下都要配一句 🔑 口诀**；整节结尾放「总口诀 + 人话版」
4. 使用场景：配考试或真实开车场景
5. 收尾标配：**速查表 + 口诀 + 一句话白话总结**
