# 6.2 故事：高速上的速度与距离

> 出场：老王（小车）、王二江（半挂大货）、小雅（第一次上高速）、老拖（救援）

---

## 第一幕 · 上高速前的"三个数"

老王把车开进收费站前，跟小雅说："高速上先记住这三个数——"

```
   ┌──────────────────────────────┐
   │                              │
   │   最  高：120 km/h            │
   │   最  低：60  km/h            │
   │                              │
   │   高速上不是越慢越安全！       │
   │   低于 60 一样违法            │
   └──────────────────────────────┘
```

小雅："慢一点还不行吗？"

老王："**不行。** 你在高速上开 40，后面的车以 120 冲过来，那就是追尾。**太慢也是害人。**"

> 🔑 **口诀：高速最高一百二，最低六十；快慢两头都违规。**

---

## 第二幕 · 三条道，各走各的速度

上了高速，眼前三条道。

```
   ┌──────────┬──────────┬──────────┐
   │  最左侧   │   中间    │  最右侧   │
   │  最低 110 │  最低 90  │  最低 60  │
   │  （小客车）│ （小客车） │ （大车）   │
   └──────────┴──────────┴──────────┘
        ↑                       ↑
   跑得最快的走这          二江的大货走这
```

| 车道 | 最低车速 |
| --- | --- |
| 同向 **2** 条车道：左侧 | **100** km/h |
| 同向 **3 条以上**：最左侧 | **110** km/h |
| 同向 **3 条以上**：中间 | **90** km/h |
| 最右侧 | **60** km/h |

### 不同车的最高速度也不一样

```
   ┌────────────────────────────────────┐
   │  小型载客汽车（老王的车）  → 最高 120 │
   │  其他机动车（二江的半挂）  → 最高 100 │
   │  摩托车（小龙）            → 最高 80  │
   └────────────────────────────────────┘
```

二江在右道跑 90，老王在中间跑 110 —— **各走各的，谁也不碍谁。**

> 🔑 **口诀：三车道 —— 左百一、中九十、右六十；小车一百二、大车一百、摩托八十。**

---

## 第三幕 · 小雅的错：在快车道开 70

小雅第一次上高速，紧张，在**最左侧快车道**只开 70。

```
   ┌──────────┬──────────┬──────────┐
   │ 🚗 70    │          │          │   ← 最左道最低 110！
   │ 小雅     │          │          │
   └──────────┴──────────┴──────────┘
   ❌ 低于最低限速
```

后面的车一辆接一辆从右侧超她、狂按喇叭。老王脸都白了：

"**快车道最低 110！你开 70，等于在高速上放了个路障。**"

```
   后果
   ┌────────────────────────────┐
   │  低于规定最低时速行驶        │
   │  → 罚款 + 记 3 分           │
   └────────────────────────────┘
```

"**开不快就走右边，别占着快车道。**"

> 🔑 **口诀：快车道要开快，开不快就往右靠；低于最低限速，三分。**

---

## 第四幕 · 车距：跟车要保持多远？

老王指着前面那辆车："**看我的跟车距离。**"

```
   车速 > 100 km/h  →  车距 ≥ 100 米
   车速 < 100 km/h  →  车距 ≥ 50 米（最小不得少于 50 米）
```

```
   ┌────────────────────────────────────────┐
   │                                        │
   │  🚗 ─────── 100 米 ─────── → 🚗          │
   │  前车                          后车     │
   │                                        │
   │  （高速上 100 米大概是两个路灯的间距）   │
   └────────────────────────────────────────┘
```

老王教了个土办法："**看见路边的距离确认牌没？** 高速上每隔一段就有 0、50、100 米的牌子，拿它量。"

> 🔑 **口诀：时速过百，车距一百；不到一百，最少五十。**

## 第五幕 · 起雾了（最重要的一节）

> 完整故事版 👉 [6.2-故事-大雾那天.md](./6.2-故事-大雾那天.md)
> （雾越来越浓的全过程：怎么判断能见度、为什么不能开远光、为什么 200 米档不开双闪）

正开着，前面起了大雾。老拖在后面用对讲机喊。

### 第一档：能见度小于 200 米

```
   ☁☁☁  能见度 < 200 米  ☁☁☁

   ┌──────────────────────────────────┐
   │  车速 ≤ 60 km/h                   │
   │  车距 ≥ 100 米                    │
   │  开灯：雾灯 + 近光灯 + 示廓灯      │
   │        + 前后位灯                 │
   └──────────────────────────────────┘
```

### 第二档：能见度小于 100 米

```
   ☁☁☁☁  能见度 < 100 米  ☁☁☁☁

   ┌──────────────────────────────────┐
   │  车速 ≤ 40 km/h                   │
   │  车距 ≥ 50 米                     │
   │  开灯：上面那些 + 危险报警闪光灯   │
   │  【并从最近出口尽快驶离】          │
   └──────────────────────────────────┘
```

### 第三档：能见度小于 50 米

```
   ☁☁☁☁☁  能见度 < 50 米  ☁☁☁☁☁

   ┌──────────────────────────────────┐
   │  车速 ≤ 20 km/h                   │
   │  开灯：同上 + 危险报警闪光灯       │
   │  【尽快驶离高速公路】              │
   └──────────────────────────────────┘
```

### 记忆图（一眼记住三档）

```
   能见度        车速        车距        动作
   ─────────────────────────────────────────
   < 200 米  →  ≤ 60    →  ≥ 100 米  → 继续开（开灯）
   < 100 米  →  ≤ 40    →  ≥ 50 米   → 找出口驶离
   <  50 米  →  ≤ 20    →  ——        → 赶紧撤！
   ─────────────────────────────────────────
   规律：能见度减半，速度减半（60→40→20），车距也减半（100→50→走人）
```

> ⚠️ **细节**：**小于 200 米时不用开危险报警闪光灯**（只开雾灯、近光灯、示廓灯、前后位灯）；**小于 100 米和小于 50 米才要加开危险报警闪光灯**。

> 🔑 **口诀：二六一百，一四五，五二赶紧撤。**
> （200 米→60 速/100 距；100 米→40 速/50 距；50 米→20 速，走人）

## 第六幕 · 老拖的提醒

```
   ╭─────────╮
   │ ⊙     ⊙ │
   │   ≡≡    │     老拖（拖车老拖）
   ╰────┬────╯
   〔反光背心〕
```

老拖："我在高速上拖了二十年车，见的都是这样的——"

```
   ❌ 雾天不开灯（别人看不见你）
   ❌ 雾天踩急刹（后车直接撞上来）
   ❌ 能见度极低还往前开（连撞十几辆）
   ❌ 在行车道上停车看热闹
```

"**雾天正确的做法：降速、开灯、拉开车距、找最近出口下去。**"

> 🔑 **口诀：雾天四件事 —— 降速、开灯、拉距、下高速。**

## 一句话总结

> **高速最高一百二、最低六十；三车道左百一中九十右六十。**
> **小车一百二、大车一百、摩托八十；开得慢别占快道。**
> **时速过百车距一百，不到一百最少五十。**
> **雾天：二六一百、一四五、五二赶紧撤，别忘了开灯。**
