# 6.2 故事：大雾那天

> 这一篇只讲一件事：**高速上起雾了，怎么办。**
> 跟着老王一家经历一场"雾越来越浓"的过程，三档规定一次记住。
> 出场：老王、小雅、王二江（半挂）、马三（反面教材）、老拖（救援）

---

## 开场 · 出发时天气还好

老王开车，小雅坐副驾，二江的半挂跟在后面。天有点阴。

```
   ┌──────────┬──────────┬──────────┐
   │  110     │   90     │   60     │
   │  🚗老王   │          │  🚛二江   │
   └──────────┴──────────┴──────────┘
```

小雅："爸，前面怎么白蒙蒙的？"

老王："**起雾了。**"

---

## 第一幕 · 第一档：能见度小于 200 米

### 怎么判断能见度？（老王的土办法）

高速路边每隔一段就有**车距确认牌**：

```
   路边依次立着三块牌子
   ┌─────┐   ┌─────┐   ┌─────┐
   │ 0 m │   │ 50m │   │100m │
   └─────┘   └─────┘   └─────┘
      ↑         ↑         ↑
    你在这儿   往前 50 米  往前 100 米
```

"**你能看到第几块牌子，就知道能见度大概多少**："
- 能看到最远的 100 米牌，看不清更远 → 能见度 **100~200 米** → 按"小于 200 米"这档办
- 只能看到 50 米牌 → 能见度 **50~100 米** → 按"小于 100 米"办
- 连 50 米牌都看不清 → 能见度 **< 50 米** → 最后一档

### 老王的操作

```
   ☁☁☁  能见度 < 200 米  ☁☁☁

   ① 减速到 ≤ 60 km/h
   ② 与前车拉开 ≥ 100 米
   ③ 开灯：雾灯 + 近光灯 + 示廓灯 + 前后位灯
```

老王一边操作一边念："**六十、一百、开雾灯。**"

> 🔑 **口诀：二百米以内 —— 六十、一百、开雾灯。**

---

## 第二幕 · 小雅的疑问：为什么不开远光？

小雅："爸，雾这么大，**开远光**看得更清楚吧？"

```
   ❌ 错误示范：
   🚗 ═══════════>  远光灯
        ☁ ☁ ☁  雾滴
        ☁ ↑ ☁
        ☁ │ ☁   光线被雾【反射回来】
        ☁ ╰─╯   → 眼前一片白，啥也看不见
```

老王："**恰恰相反。远光打在雾上会散射，眼前一片白，更瞎。**"

```
   ✅ 正确：
   🚗 ────>  近光灯 + 雾灯
        ☁ ☁ ☁   雾灯穿透力强、位置低
        ☁ ── ☁   能照到路面，还不晃眼
```

> **原理**：雾灯装在**车头下方**、**色温偏黄**、**穿透力强**，光是"贴着地"照出去的；远光位置高、角度平，正好打在雾上反射回来。

> 🔑 **口诀：雾天开远光，越开越白 —— 只开近光和雾灯。**

### 马三的反面示范

后面马三开着远光冲过来，还一脚急刹。

```
   ╭─────────╮
   │ ██   ██ │
   │    ◡    │     马三：远光 + 急刹
   ╰────┬────╯
   〔刹车灯〕
```

"**咣——**"追尾了。

老王："**雾天两件傻事：开远光、急刹车。** 后车根本看不见你刹车灯，一脚急刹就是连环撞。"

```
   雾天刹车正确做法：
   ✅ 提前【缓】踩，点刹提示后车
   ❌ 一脚闷死
```

> 🔑 **口诀：雾天不急刹，提前点刹提醒后车。**

## 第三幕 · 第二档：能见度小于 100 米

雾更浓了，连 100 米牌都看不清了。

```
   ☁☁☁☁  能见度 < 100 米  ☁☁☁☁

   ① 减速到 ≤ 40 km/h
   ② 车距 ≥ 50 米
   ③ 加开【危险报警闪光灯】（双闪）
   ④ 【从最近的出口尽快驶离高速】
```

小雅："这回为啥**能开双闪**了？"

老王："**因为这时候你已经不是'正常行驶'了，是在'挣扎着找出口'。** 双闪是告诉别人：我这儿有情况，别靠近。"

```
   为什么 200 米那档不开双闪？
   ┌────────────────────────────────┐
   │  < 200 米：还能正常开，开双闪反而  │
   │  会【掩盖转向灯】，变道时别人看不出 │
   │  你要往哪拐 —— 更危险              │
   │                                  │
   │  < 100 米：已经在找出口撤离，      │
   │  双闪用来警示后车                 │
   └────────────────────────────────┘
```

> 🔑 **口诀：一百米内 —— 四十、五十、开双闪、找出口。**

---

## 第四幕 · 二江的大货怎么办？

二江的半挂在后面，用对讲机喊："哥，我这大货雾里更难停，**怎么办？**"

```
       ______       ┌────────────────────┐
      |  __  |      │                    │
      | |  | |______│     集装箱挂厢     │
      |_|__|_|      │                    │
        (o)         └────────────────────┘
```

老王："**你走最右道，速度压到 40 以下，拉开车距，跟着我找出口。**"

```
   大车在雾天更危险的原因：
   ┌──────────────────────────────┐
   │  ① 车重、刹不住（制动距离长）  │
   │  ② 车身长，挡住后车视线        │
   │  ③ 一旦追尾，小车直接钻进去    │
   └──────────────────────────────┘
```

> 🔑 **口诀：大车走右道、压速、拉距，别在快道上磨蹭。**

---

## 第五幕 · 第三档：能见度小于 50 米

雾浓到连 50 米牌都看不见了。

```
   ☁☁☁☁☁  能见度 < 50 米  ☁☁☁☁☁

   ① 车速 ≤ 20 km/h
   ② 开：雾灯 + 近光灯 + 示廓灯 + 前后位灯 + 双闪
   ③ 【尽快驶离高速公路】
```

老拖的救援车闪着灯从后面上来，用喇叭喊话引导：

```
   ╭─────────╮
   │ ⊙     ⊙ │
   │   ≡≡    │     老拖（拖车老拖）
   ╰────┬────╯
   〔反光背心 + 喇叭：跟着我走！〕
```

"**别停！跟着我，两公里后有出口！**"

```
   ⚠️ 关键：50 米这档【不停在行车道上】
   
   ❌ 就地停车看热闹 → 后车连环撞
   ✅ 以 ≤20 的速度慢慢挪到出口
```

> 🔑 **口诀：五十米内 —— 二十码、开双闪、跟着引导撤，千万别停在道上。**

---

## 第六幕 · 安全下高速

三辆车跟着老拖，从最近出口驶离，在服务区等雾散。

小雅在服务区画了张表：

```
   能见度        车速      车距       双闪    动作
   ─────────────────────────────────────────────
   < 200 米     ≤ 60     ≥ 100 米   ✗     继续开（开雾灯）
   < 100 米     ≤ 40     ≥ 50 米    ✓     找出口撤离
   <  50 米     ≤ 20     ——         ✓     赶紧撤，别停道上
   ─────────────────────────────────────────────
   规律：能见度减半 → 速度减半（60→40→20）
         车距也减半 →（100→50→走人）
```

**灯光对照**：

```
   ┌────────────────────────────────────────┐
   │  < 200 米：雾灯 + 近光灯 + 示廓灯 + 前后位灯│
   │  < 100 米：上面 + 危险报警闪光灯           │
   │  <  50 米：同上                           │
   │                                          │
   │  全程【禁止】：远光灯                     │
   └────────────────────────────────────────┘
```

---

## 一句话总结

> **二百米：六十、一百、开雾灯（不开双闪、不开远光）。**
> **一百米：四十、五十、加双闪、找出口。**
> **五十米：二十码、跟引导撤，千万别停在道上。**
> **雾天两件傻事：开远光、急刹车。**
